Can Userscripts Run on Local HTML Files?

Yes, userscripts can run on local HTML files stored on your computer, but they do not do so by default due to browser security restrictions. To execute custom scripts on local files, you must grant your browser extension permission to access file URLs and set the correct file matching patterns in your script's metadata header.

Step 1: Grant Extension Permissions

Most modern web browsers block extensions from reading local files (file:// URLs) to protect system security. You must manually lift this restriction for your specific userscript manager (such as Tampermonkey, Violentmonkey, or Greasemonkey).

Google Chrome, Brave, and Microsoft Edge

  1. Open the browser menu and navigate to Extensions > Manage Extensions (or type chrome://extensions in the address bar).
  2. Find your script manager extension and click Details.
  3. Scroll down and locate Allow access to file URLs.
  4. Toggle the switch to On.

Mozilla Firefox

  1. Navigate to about:addons in your address bar.
  2. Select your userscript manager.
  3. Under the Permissions tab, ensure that access to local files and user data is allowed.

Step 2: Update Script Header Metadata

After enabling browser permissions, you must update the userscript header to match local file paths using the file:// scheme.

Modify the @match or @include directives in your script's metadata block:

// ==UserScript==
// @name         Local File Automation
// @namespace    http://tampermonkey.net/
// @version      1.0
// @match        file:///*
// @grant        none
// ==UserScript==

(function() {
    'use strict';
    console.log('Userscript is running on a local file!');
})();

Targeting Specific Files or Folders

  • Match every local file: file:///*
  • Match specific extensions: file:///*/*.html
  • Match a specific local folder: file:///C:/Users/YourName/Projects/*

Step 3: Verify Script Execution

  1. Double-click or open your local .html file inside your web browser.
  2. Ensure the URL bar shows a path starting with file:///.
  3. Click your userscript manager extension icon to check if the script is recognized as active on the current page.
  4. Press F12 to open Developer Tools and check the Console tab to verify that your script outputs logs or functions as expected.
