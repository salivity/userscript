Auto Accept Cookie Banners with Userscripts

Yes, userscripts can be used to automatically accept, reject, or hide cookie consent banners across the web. By utilizing browser extensions like Tampermonkey, Violentmonkey, or Greasemonkey, users can run lightweight JavaScript programs that detect consent pop-ups in real-time and execute preset actions. This automates the decision-making process, eliminating constant prompt interruptions while browsing.

How Userscripts Handle Cookie Banners

Userscripts interact directly with a webpage's Document Object Model (DOM). When a web page loads, the script scans the page for specific code structures, IDs, classes, or text patterns associated with common cookie banners (such as OneTrust, Cookiebot, or Didomi).

Once detected, the script can handle the banner in three primary ways:

  1. Auto-Rejecting / Minimal Consent: The script targets and clicks the "Reject All," "Decline," or "Necessary Only" button. This is the preferred method for privacy-conscious users.
  2. Auto-Accepting: The script automatically clicks "Accept All" or "Allow Cookies" to dismiss the prompt immediately without care for tracking preferences.
  3. Hiding/Deleting Elements: The script alters the page's CSS or removes the cookie banner HTML element directly from the page. While this hides the banner, it may leave the site in its default consent state (which varies by region).

Popular Pre-Made Userscripts

Instead of writing scripts from scratch, users can install popular existing solutions maintained by the open-source community on platforms like Greasy Fork or OpenUserJS:

  • I don't care about cookies (Userscript version): Automatically accepts or hides cookie pop-ups on thousands of websites.
  • Consent-O-Matic (Ported Scripts): Focuses on automatically filling out CMP (Consent Management Platform) forms to set privacy preferences to the maximum allowed refusal level.
  • Generic Banner Blockers: Scripts that target common CSS frameworks to hide fixed overlays and restore page scrolling.

How to Set Up a Userscript for Cookie Banners

  1. Install a Script Manager: Add a browser extension such as Tampermonkey, Violentmonkey, or Greasemonkey to your browser.
  2. Find or Write a Script: Search script repositories for "cookie consent" or write a basic script using standard DOM selection methods (document.querySelector()).
  3. Enable and Configure: Activate the script within your manager extension. Most scripts work silently in the background without requiring user input.

Limitations and Challenges

While effective, userscript-based cookie automation has a few limitations:

  • Frequent Site Updates: Websites frequently change their code layout and class names, which can break targeted selectors until the script maintainer updates them.
  • Shadow DOM and IFrames: Modern CMPs sometimes embed banners inside Shadow DOMs or cross-origin IFrames, making them harder for simple userscripts to detect and click.
  • Page Scroll Locks: Merely deleting a banner element often leaves the overflow: hidden CSS rule intact on the page body, preventing the user from scrolling until additional script logic restores scrolling capabilities.
