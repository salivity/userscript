Understanding @contributionURL in Userscripts

The @contributionURL tag is a metadata directive used in userscript development to link users directly to a creator's donation page. By defining this tag within the metadata block of a script, developers provide users with a seamless way to financially support their work directly through popular userscript managers like Tampermonkey, Violentmonkey, and Greasemonkey.

What is the @contributionURL Tag?

In userscript development, the metadata block contains directives that tell the browser extension manager how the script should behave, where it should run, and who created it. The @contributionURL key is a optional header key designed specifically for monetization and community support.

It allows script authors to attach a link pointing to funding platforms such as:

  • PayPal
  • Patreon
  • Ko-fi
  • GitHub Sponsors
  • Custom donation pages

How @contributionURL Facilitates Donations

The @contributionURL tag bridges the gap between script creators and users who want to express gratitude for free tools. It facilitates donations through several mechanisms:

1. Integrated UI Support

When a userscript manager detects the @contributionURL tag, it often renders a visible "Donate," "Contribute," or heart icon next to the script’s name in the manager's dashboard or popup menu. Users do not need to hunt through the source code or visit an external script repository to find a way to tip the author.

2. Direct-to-Payment Redirection

Clicking the contribution link within the extension interface immediately redirects the user to the developer's specified payment gateway. This reduces friction, making spontaneous donations more likely.

3. Standardization Across Platforms

Because @contributionURL is a recognized standard across main userscript managers, developers only need to define the URL once in their code. The user experience remains consistent regardless of whether a user runs Tampermonkey on Chrome, Violentmonkey on Firefox, or another setup.

Syntax and Implementation

To implement the tag, place it within the ==UserScript== metadata block at the top of your JavaScript file:

// ==UserScript==
// @name         Example Userscript
// @namespace    http://tampermonkey.net/
// @version      1.0
// @description  A useful script for browser customization.
// @author       Your Name
// @match        https://example.com/*
// @contributionURL https://www.buymeacoffee.com/yourusername
// ==/UserScript==

Some script managers also support optional parameters like @contributionAmount to suggest a default donation value, though @contributionURL is the primary tag required to enable the link.
