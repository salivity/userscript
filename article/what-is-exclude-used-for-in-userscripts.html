What Is @exclude Used for in Userscripts?

The @exclude directive in userscripts is a metadata header tag used to explicitly prevent a script from running on specific web pages or URL patterns. Even if a URL matches a target page defined by an @include or @match directive, an @exclude rule takes absolute precedence, ensuring the script remains inactive on blacklisted pages.

How @exclude Works

Userscript managers (such as Tampermonkey, Greasemonkey, and Violentmonkey) parse the metadata block at the top of a script to determine when and where to inject the code.

While @match and @include create a whitelist of target web pages, @exclude acts as a blacklist. If a URL satisfies both a @match rule and an @exclude rule, the userscript manager prioritizes the @exclude directive and blocks execution.

Syntax and Matching Rules

The @exclude directive accepts full URLs, partial paths, and standard wildcard patterns using the asterisk (*) character:

  • Exact Match: Excludes one specific web page. // @exclude https://example.com/login
  • Wildcard Path Match: Excludes an entire directory or path structure. // @exclude https://example.com/cart/*
  • Subdomain Match: Excludes all subdomains under a domain. // @exclude https://*.example.com/*
  • Global Wildcard: Excludes a path across all protocols and domains. // @exclude *://*/checkout/*

Primary Use Cases

  1. Protecting Sensitive Pages: Disabling custom scripts on login forms, account settings, or payment gateways to maintain security and privacy.
  2. Avoiding Script Conflicts: Preventing a script from attempting to modify pages where it breaks native site functionality, such as dynamic web applications or checkout systems.
  3. Improving Performance: Skipping heavy web pages or web utility tools on a domain where script modifications are unnecessary.

Code Example

// ==UserScript==
// @name         Site Customizer
// @namespace    http://example.com/
// @version      1.0
// @match        https://example.com/*
// @exclude      https://example.com/checkout/*
// @exclude      https://example.com/login
// ==/UserScript==

console.log("This script runs on example.com, but never on the login or checkout pages.");
