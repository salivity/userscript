Extract Subtitles from Video Streams with Userscripts

Yes, userscripts can automatically extract and download subtitle files, such as WebVTT (.vtt) or SubRip (.srt), from online video streams. By executing custom JavaScript directly in your web browser using extensions like Tampermonkey or Violentmonkey, userscripts can monitor network activity, read video player data, convert subtitle formats, and automatically trigger browser downloads.

How Userscripts Extract Subtitles

Userscripts use three main techniques to detect and capture subtitle data from video players:

1. Intercepting Network Requests

Most modern video platforms stream subtitles as separate text files or API responses via fetch or XMLHttpRequest (XHR) requests. A userscript can override the browser's native fetch or XHR methods to inspect outgoing requests and incoming responses. When the script detects a URL ending in .vtt, .srt, or containing subtitle JSON payloads, it captures the raw text content or saves the URL for direct download.

2. Inspecting the DOM and Player APIs

If a video player loads subtitles into the HTML document using standard <track> elements, userscripts can query the Document Object Model (DOM) to find the source URLs:

const track = document.querySelector('track[kind="subtitles"]');
const subtitleUrl = track ? track.src : null;

Additionally, many custom HTML5 players expose global JavaScript variables or internal APIs that store subtitle tracks, timing data, and language options. Userscripts can access these player objects directly to retrieve hidden subtitle streams.

3. Parsing HLS and DASH Manifests

For adaptive streaming protocols like HTTP Live Streaming (HLS) or Dynamic Adaptive Streaming over HTTP (DASH), subtitle tracks are listed within master playlist files (.m3u8 or .mpd). Userscripts can parse these manifest files, locate the URIs for the subtitle fragments, fetch the individual segments, and stitch them together into a single file.

Converting and Downloading Subtitles

Once a userscript captures raw subtitle data, it can process and download the file automatically:

  • Format Conversion: WebVTT files can easily be parsed and converted into the widely supported SRT format using regex or simple JavaScript string operations (e.g., replacing . with , in timestamps and adjusting headers).
  • Automatic Downloading: Userscripts create a Blob object from the subtitle text and generate a temporary download link using URL.createObjectURL(), or they utilize userscript-specific functions like GM_download to bypass cross-origin restrictions and save the file to your device.

Limitations

While userscripts are highly effective, they have a few technical boundaries:

  • Hardcoded Subtitles: Userscripts cannot extract subtitles that are baked directly into the video frames (open captions). Capturing hardcoded text requires Optical Character Recognition (OCR) software.
  • Encrypted Streams (DRM): If subtitle tracks are protected by Digital Rights Management (DRM) systems, the payload may be encrypted, preventing the userscript from reading the plain text.
