How Userscripts Parse Deeply Nested Intercepted JSON

Userscripts intercept network traffic by overriding native web browser APIs such as fetch and XMLHttpRequest, allowing developers to read and alter data transferred between a client and a server. When network responses contain deeply nested JSON, userscripts use a combination of monkey-patching, string parsing, defensive navigation techniques, and structural traversal to access and modify hidden data points safely without breaking the host application.

Intercepting Network Traffic

Before interacting with JSON, a userscript must intercept the incoming payload. This is typically achieved by overriding the browser's global asynchronous request handlers before the web application executes its own scripts.

For fetch requests, userscripts redefine window.fetch:

const originalFetch = window.fetch;
window.fetch = async function (...args) {
  const response = await originalFetch.apply(this, args);
  const clonedResponse = response.clone();
  
  clonedResponse.json().then(data => {
    handleNestedJson(data);
  });

  return response;
};

For older or alternative implementations using XMLHttpRequest, the script patches XHR.prototype.open or XHR.prototype.send and adds an event listener for readystatechange or load.

Parsing the Response Body

Once intercepted, the raw payload exists as a JSON-formatted string, a ReadableStream, or an ArrayBuffer. Userscripts convert raw text into an actionable JavaScript object using JSON.parse(). Because dynamic network traffic can occasionally yield malformed data, parsing is always wrapped in error-handling blocks to prevent script termination.

function safeParse(rawText) {
  try {
    return JSON.parse(rawText);
  } catch (error) {
    console.error("Failed to parse JSON response:", error);
    return null;
  }
}

Accessing Deeply Nested Properties

Deeply nested JSON responses often contain long paths, such as response.data.user.settings.notifications.email.enabled. If any intermediate key is missing or null, standard dot-notation throws an exception. Userscripts employ several patterns to safely navigate these structures.

1. Optional Chaining and Nullish Coalescing

Modern JavaScript engines support optional chaining (?.), which stops evaluation and returns undefined if an intermediate reference is null or undefined.

const isEmailEnabled = data?.data?.user?.settings?.notifications?.email?.enabled ?? false;

2. Recursive Traversal

When the exact structural depth or path is dynamic, userscripts use recursive functions to search for target keys across arbitrary nested levels.

function findNestedKey(obj, targetKey) {
  if (typeof obj !== 'object' || obj === null) return null;
  if (Object.prototype.hasOwnProperty.call(obj, targetKey)) return obj[targetKey];

  for (const key of Object.keys(obj)) {
    const result = findNestedKey(obj[key], targetKey);
    if (result !== null) return result;
  }
  return null;
}

3. Destructuring with Default Values

When extracting multiple values from a known nested branch, destructuring simplifies the syntax while providing fallback values.

const {
  data: {
    user: {
      profile: { id = null, username = 'Guest' } = {}
    } = {}
  } = {}
} = responseData;

Modifying and Re-injecting Nested Data

To alter web page behavior, userscripts often modify deeply nested values within the intercepted object and construct a new Response object to return to the web application.

window.fetch = async function (...args) {
  const response = await originalFetch.apply(this, args);
  const data = await response.json();

  // Modify a nested property deep inside the object
  if (data?.config?.features?.betaAccess !== undefined) {
    data.config.features.betaAccess = true;
  }

  // Return a new response stream containing the modified JSON
  return new Response(JSON.stringify(data), {
    status: response.status,
    statusText: response.statusText,
    headers: response.headers
  });
};

By safely parsing payloads, handling variable depths with guarded accessors, and reconstructing responses, userscripts reliably read and transform complex network traffic in real time.
