How to Inject React into Webpages via Userscript

Injecting a React application into an existing webpage using a userscript allows developers to add custom, interactive interfaces to any website. The process involves creating a host container within the webpage's Document Object Model (DOM), loading the React and ReactDOM libraries, and mounting the React component tree into that host container. This can be accomplished using plain JavaScript in userscript managers like Tampermonkey, or through modern build tools like Vite and Webpack.

Step 1: Set Up the Userscript Metadata

Userscript managers rely on a metadata block at the top of the script file. You need to define the target URLs with @match and load the React and ReactDOM libraries using @require directives if you are not bundling them directly into your build.

// ==UserScript==
// @name         React Page Injector
// @namespace    http://tampermonkey.net/
// @version      1.0
// @match        https://example.com/*
// @require      https://unpkg.com/react@18/umd/react.production.min.js
// @require      https://unpkg.com/react-dom@18/umd/react-dom.production.min.js
// ==UserScript==

Step 2: Create a Host Element in the DOM

Before mounting the React app, you must create an HTML element to serve as the root container. Append this element to an appropriate location in the host webpage, such as document.body or a specific container on the page.

const appContainer = document.createElement('div');
appContainer.id = 'my-custom-react-root';
document.body.appendChild(appContainer);

To prevent the target website's CSS from breaking your React app's styles (and vice versa), you can attach a Shadow DOM to this host element:

const shadowRoot = appContainer.attachShadow({ mode: 'open' });
const reactMountPoint = document.createElement('div');
shadowRoot.appendChild(reactMountPoint);

Step 3: Define the React Component

If writing plain JavaScript without a build step, define components using React.createElement. If using JSX, compiling through a bundler like Babel, Vite, or Webpack is required before the userscript executes.

function App() {
    return React.createElement(
        'div',
        { style: { padding: '10px', background: '#fff', border: '1px solid #ccc' } },
        'Hello from injected React application!'
    );
}

Step 4: Mount the React Application

Use ReactDOM.createRoot (for React 18+) to render the application into your created DOM element or shadow root.

const root = ReactDOM.createRoot(reactMountPoint || appContainer);
root.render(React.createElement(App));

Step 5: Build Automation (Recommended)

For complex React applications containing JSX, CSS styles, or third-party packages, manually writing React.createElement is impractical. Using build plugins like vite-plugin-monkey simplifies this workflow by automatically bundling JSX code, CSS styles, and dependencies into a single .user.js file ready for installation.
