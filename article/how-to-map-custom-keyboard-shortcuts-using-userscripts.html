How to Map Custom Keyboard Shortcuts Using Userscripts

Userscripts can fully map custom keyboard shortcuts to perform specific web page actions. Browser script managers such as Tampermonkey, Violentmonkey, or Greasemonkey allow you to execute custom JavaScript on target websites, listening for user keypresses and triggering interactions like clicking buttons, navigating pages, or toggling UI elements. This article explains how keyboard shortcuts work within userscripts, provides a functional code example, and details best practices for handling browser defaults and input fields.

How Shortcut Userscripts Function

Userscripts manipulate the web page by attaching global event listeners to the window or document object. When a user presses a key, the browser generates a keydown or keyup event. The script captures this event, checks if the pressed key combination matches your designated shortcut, and executes the target action by interacting with the Document Object Model (DOM).

Basic Userscript Example

Below is a complete JavaScript template for a userscript that triggers a site action using a custom shortcut (e.g., pressing Shift + G to click a specific button).

// ==UserScript==
// @name         Custom Keyboard Shortcut Mapper
// @namespace    http://tampermonkey.net/
// @version      1.0
// @description  Map custom keys to page actions
// @match        https://example.com/*
// @grant        none
// ==UserScript==

(function() {
    'function' === typeof window.addEventListener && window.addEventListener('keydown', function(event) {
        // Prevent shortcuts from triggering while typing in input fields
        const activeElement = document.activeElement;
        const isInputField = activeElement.tagName === 'INPUT' || 
                             activeElement.tagName === 'TEXTAREA' || 
                             activeElement.isContentEditable;

        if (isInputField) return;

        // Example: Trigger action on Shift + G
        if (event.shiftKey && event.key.toLowerCase() === 'g') {
            event.preventDefault(); // Stop default page/browser behavior

            // Target a specific element on the page and perform an action
            const targetButton = document.querySelector('.submit-btn');
            if (targetButton) {
                targetButton.click();
            }
        }
    });
})();

Essential Implementation Rules

1. Ignore Active Input Fields

Without proper checks, your custom shortcuts will trigger while typing standard text into search bars, comment boxes, or form fields. Always inspect document.activeElement to verify the user is not currently focused inside an <input>, <textarea>, or contenteditable element before executing a shortcut action.

2. Prevent Default Browser Behaviors

Many key combinations are reserved by browsers (such as Ctrl + S for saving or Ctrl + P for printing). Calling event.preventDefault() inside your listener stops the browser's native response so only your script's designated action executes.

3. Handle Modifier Keys Accurately

To map complex combinations, evaluate the Boolean properties attached to the event object:

  • event.ctrlKey (Control key)
  • event.altKey (Alt / Option key)
  • event.shiftKey (Shift key)
  • event.metaKey (Command key on macOS, Windows key on Windows)

Match these modifiers with event.key or event.code to ensure cross-platform consistency.
