What is the Userscript @description Metadata Tag?

The @description metadata tag is a core attribute defined within a userscript's header block that provides a concise summary of the script's functionality. This article explains what the @description tag is, how script repositories and browser extensions utilize it, and why optimizing this tag is critical for improving the discoverability and searchability of your userscripts.

Understanding the @description Metadata Tag

A userscript relies on a metadata block—a specialized block of comments at the top of the file—to communicate instructions to userscript managers like Tampermonkey, Violentmonkey, or GreaseMonkey.

The @description tag specifies a short text string that outlines what the script does, which web pages it modifies, or what features it adds.

// ==UserScript==
// @name         Dark Mode Toggle for Example
// @namespace    http://tampermonkey.net/
// @version      1.0
// @description  Adds a clean dark mode toggle button to the top navigation bar of Example.com.
// @author       You
// @match        https://example.com/*
// ==UserScript==

If no @description tag is present, userscript managers and hosting platforms usually leave the summary blank or fall back to displaying the script's @name, offering minimal context to potential users.

How the @description Tag Affects Searchability

The text within the @description tag plays a direct role in how users locate and decide to install your script.

1. On-Platform Search Indexing

Platforms like Greasy Fork, OpenUserJS, and GitHub index userscript metadata. When users enter queries into the search bar of a script repository, the search engine scans both the @name and @description tags to return relevant results. Including accurate terms and site names in the description ensures the script ranks for appropriate internal queries.

2. External Search Engine Optimization (SEO)

Search engines like Google and Bing crawl public script repositories. These platforms frequently populate their page metadata, search snippets, and preview cards using the content of the @description tag. A well-written tag helps web search engines surface your script to users searching for solutions to specific web browsing issues.

3. Manager UI Search and Filtering

Browser extensions allow users to manage dozens of installed scripts. The internal search features within Tampermonkey or Violentmonkey search through local metadata, enabling users to quickly locate, enable, or disable specific scripts based on keywords contained in their descriptions.

4. Click-Through Rates and User Retention

Searchability extends beyond showing up in search results; it includes converting impressions into installs. A clear, specific @description tag informs users immediately whether a script meets their needs, resulting in higher installation rates and lower uninstall rates caused by mismatched expectations.

Best Practices for Writing @description Tags

To maximize discoverability while maintaining clarity:

  • Include Primary Keywords: Mention the targeted website, the core feature, and key actions (e.g., "ad remover," "theme," "exporter").
  • Keep It Concise: Aim for 10 to 25 words. Summarize the core purpose without filler language.
  • Avoid Keyword Stuffing: Write naturally for human readers. Excessive keyword lists can hurt rankings on modern search engines and deter users.
  • Specify Localizations: If your script targets non-English users, utilize localized description tags (such as @description:es or @description:zh-CN) to expand discoverability in regional search queries.
