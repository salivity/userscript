Auto Collapse Hacker News Threads with Userscripts

Userscripts can easily automate the expanding and collapsing of nested conversation threads on web platforms like Hacker News, Reddit, and online forums. By executing custom JavaScript directly in your browser, userscripts manipulate the webpage's Document Object Model (DOM) to automatically hide deep reply chains, expand top-level responses, or add keyboard shortcuts for seamless comment navigation.

How Userscripts Control Conversation Threads

Websites render nested comment threads using HTML structures tied to CSS classes and JavaScript click events. On Hacker News, for example, each comment contains a toggle element—typically represented as a [-] button—that hides or reveals child comments.

A userscript automates this interaction by targeting specific elements on page load. It scans the DOM for nested comment tiers and triggers the collapse function for any reply beyond a specified depth.

Key Features Implemented by Thread Management Scripts

  • Automatic Depth Collapsing: Scripts can automatically collapse all replies deeper than a set level (for example, hiding level-3 replies and below) to keep long discussions readable.
  • Keyboard Navigation: Userscripts can map keybindings (like j and k to move between top-level comments, or c to toggle a thread) to navigate without a mouse.
  • Smart Filtering: Advanced scripts allow users to collapse threads based on specific criteria, such as low karma scores, specific keywords, or collapsed states previously saved in local storage.
  • Sticky Top-Level Comments: Keep primary responses visible while automatically tucking away lengthy side conversations.

How to Set Up a Thread Userscript

To use or build a thread-collapsing script:

  1. Install a Manager: Install a browser extension such as Tampermonkey or Violentmonkey.
  2. Find or Write a Script: Search script repositories like Greasy Fork for existing Hacker News thread tools, or write a custom JavaScript snippet targeting the page's comment elements.
  3. Configure Match Rules: Ensure the script's @match directive points to https://news.ycombinator.com/item?id=* so it runs exclusively on discussion pages.

By leveraging simple DOM manipulation routines, userscripts provide complete control over how complex, multi-layered discussions are displayed, drastically reducing the clutter of deep comment trees on text-heavy sites.
