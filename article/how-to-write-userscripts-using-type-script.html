How to Write Userscripts Using TypeScript

Writing userscripts with TypeScript improves code quality, provides autocompletion for browser and Tampermonkey APIs, and allows you to use modern JavaScript features with static type checking. The overall process involves setting up a local development environment, installing TypeScript and standard type definitions, configuring a bundler to compile your code into a single executable .user.js file with a metadata header, and linking that output file to a script manager such as Tampermonkey or Violentmonkey.

1. Project Initialization and Dependency Installation

Userscripts run directly in the browser, but because TypeScript requires compilation and userscripts must exist as a single file, you need a Node.js project environment.

Initialize a new project and install TypeScript alongside essential type definitions:

npm init -y
npm install --save-dev typescript @types/tampermonkey

Installing @types/tampermonkey (or types for your preferred manager) provides autocompletion and type safety for global userscript functions like GM_xmlhttpRequest, GM_setValue, and GM_getValue.

2. Configure TypeScript (tsconfig.json)

Create a tsconfig.json file in your root directory to instruct the TypeScript compiler on how to handle your code:

{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "node",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "lib": ["DOM", "DOM.Iterable", "ES2022"]
  },
  "include": ["src/**/*"]
}

3. Set Up a Bundler

Browser script managers require userscripts to be bundled into a single standalone file. Tools like Vite, Rollup, or Webpack work well for this task. Using Rollup with @rollup/plugin-typescript is a lightweight approach.

Install Rollup dependencies:

npm install --save-dev rollup @rollup/plugin-typescript @rollup/plugin-node-resolve

Create a rollup.config.js file:

import typescript from '@rollup/plugin-typescript';
import resolve from '@rollup/plugin-node-resolve';
import fs from 'fs';

const banner = fs.readFileSync('./src/meta.js', 'utf8');

export default {
  input: 'src/index.ts',
  output: {
    file: 'dist/my-script.user.js',
    format: 'iife',
    banner: banner
  },
  plugins: [
    resolve(),
    typescript()
  ]
};

4. Define the Userscript Metadata Header

Userscript managers rely on a specific metadata block at the top of the file to determine script permissions, target URLs, and running conditions. Create src/meta.js:

// ==UserScript==
// @name         TypeScript Userscript Template
// @namespace    http://tampermonkey.net/
// @version      1.0.0
// @description  A clean setup for writing userscripts in TypeScript.
// @author       Your Name
// @match        https://example.com/*
// @grant        GM_getValue
// @grant        GM_setValue
// ==UserScript==

5. Write Your Script

Create your entry point file at src/index.ts. You can now use full TypeScript features and browser/Tampermonkey APIs securely:

function init(): void {
  const heading = document.querySelector('h1');
  if (heading) {
    heading.style.color = 'red';
  }

  // Type-checked Tampermonkey API call
  GM_setValue('lastRun', Date.now());
  console.log('Last run saved:', GM_getValue('lastRun'));
}

window.addEventListener('load', init);

6. Build and Install

Add build scripts to your package.json:

"scripts": {
  "build": "rollup -c",
  "watch": "rollup -c --watch"
}

Run npm run build to generate dist/my-script.user.js.

To load the script into your browser:

  1. Open Tampermonkey or Violentmonkey in your browser.
  2. Create a new script.
  3. Paste the contents of dist/my-script.user.js into the editor, or set up local file access / a local HTTP server (npx serve dist) to automatically update the script whenever you run npm run watch.
