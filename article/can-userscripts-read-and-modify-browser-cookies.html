Can Userscripts Read and Modify Browser Cookies?

Userscripts have the capability to read, modify, and delete browser cookies, though their access level depends on standard web security rules and the powers granted by your userscript manager. While standard userscripts interacting directly with a webpage are restricted by traditional browser security features like HttpOnly flags, advanced scripts using specialized extension APIs can bypass these restrictions to gain full control over cookie management.

Standard Access via JavaScript

At the basic level, userscripts run within the context of the webpage. This means they can interact with the Document Object Model (DOM) using standard JavaScript.

  • Reading Cookies: A script can read accessible cookies by accessing document.cookie.
  • Modifying and Creating Cookies: A script can set or update cookies by assigning new key-value pairs to document.cookie.
  • Limitations: Standard scripts cannot access cookies protected by the HttpOnly flag. Browsers deliberately block client-side JavaScript from reading or altering HttpOnly cookies to protect sensitive session data from Cross-Site Scripting (XSS) attacks.

Advanced Access via Userscript Manager APIs

Popular userscript managers—such as Tampermonkey, Violentmonkey, and Greasemonkey—provide extended APIs that give scripts elevated privileges beyond standard webpage limitations.

  • The GM_cookie API: By requesting the @grant GM_cookie (or GM.cookie) directive in the script's metadata block, a userscript gains access to the browser extension's cookie management engine.
  • Bypassing HttpOnly Restrictions: The GM_cookie API operates at the browser extension level rather than the web page level. This allows the script to read, modify, create, and delete even HttpOnly cookies.
  • Cross-Domain Access: With appropriate URL permissions in the script header, scripts can manage cookies for domains other than the currently active tab.

Security and Privacy Implications

Because userscripts can access powerful APIs like GM_cookie, installing untrusted scripts poses a significant security risk. A malicious userscript with cookie permissions can steal session tokens, hijack accounts, or alter site preferences without your knowledge. Always review the source code and requested @grant permissions of a userscript before installing it.
