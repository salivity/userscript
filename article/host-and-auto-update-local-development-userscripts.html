Host and Auto Update Local Development Userscripts

Setting up a local web server to host and auto-update userscripts allows developers to iterate quickly on browser extensions like Tampermonkey or Violentmonkey without manually copying and pasting code. By running a simple HTTP server on your machine, configuring specific user script metadata tags (@updateURL and @downloadURL), and tweaking your script manager’s update settings, you can establish an automated pipeline where local file saves instantly reflect in your browser.

1. Directory Setup and Script Metadata

Create a dedicated folder for your project and add your script file using the .user.js extension (e.g., myscript.user.js).

At the top of your script, include the required metadata block containing the @version, @updateURL, and @downloadURL headers:

// ==UserScript==
// @name         Local Auto-Update Script
// @namespace    http://localhost/
// @version      1.0.0
// @description  Development script hosted on a local web server
// @match        https://example.com/*
// @updateURL    http://localhost:8080/myscript.user.js
// @downloadURL  http://localhost:8080/myscript.user.js
// ==UserScript==

console.log("Userscript loaded from local server!");

2. Launch a Local Web Server

Run a lightweight command-line server inside your project directory to serve the file locally over HTTP.

Option A: Python

Run this command in your project directory:

python3 -m http.server 8080

Option B: Node.js (http-server)

If you have Node.js installed, run:

npx http-server -p 8080 --cors

Your script will now be accessible at http://localhost:8080/myscript.user.js.

3. Initial Script Installation

  1. Open your web browser.
  2. Navigate to http://localhost:8080/myscript.user.js.
  3. Your userscript manager extension (Tampermonkey, Violentmonkey, or Greasemonkey) will detect the .user.js extension and open the installation prompt.
  4. Click Install.

4. Configure Auto-Update Settings

To ensure your browser extension picks up changes quickly:

  1. Open your userscript manager's dashboard and go to Settings.
  2. Change the Config Mode to Advanced (if using Tampermonkey).
  3. Set the Update Interval to the shortest possible timeframe (e.g., "Every hour" or "Every start").
  4. Enable External update checks or allow localhost origin permissions if prompted by the extension.

5. Daily Development Workflow

  1. Edit your local myscript.user.js file.
  2. Increment the @version tag (e.g., change 1.0.0 to 1.0.1).
  3. Save the file.
  4. Refresh the target website page, or trigger a manual update check from the extension icon menu to fetch the newest build immediately.
