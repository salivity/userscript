Auto Format Raw JSON in Browser Using Userscripts

Yes, userscripts can be used to automatically format raw JSON data displayed in a web browser window. By utilizing browser extensions like Tampermonkey, Violentmonkey, or Greasemonkey, a custom JavaScript script can detect when a page contains unformatted JSON text, parse that data, and dynamically replace the plain text with a structured, collapsible, and syntax-highlighted HTML layout.

How Userscripts Process Raw JSON Data

When a browser fetches an API endpoint or a raw .json file, it typically displays the response as an unformatted text string. A userscript automates the formatting process using the following workflow:

  1. Detection: The script checks the document's content type or inspects the body text to verify if the content is valid JSON.
  2. Parsing: The raw string is processed using JSON.parse() to turn it into a readable JavaScript object.
  3. Rendering: The script constructs formatted HTML elements—adding indentation, color coding for keys and values, and interactive elements like toggle arrows for collapsing objects or arrays.
  4. DOM Replacement: The raw document body is cleared and replaced with the newly generated, styled tree view.

A Basic Userscript Implementation

Below is a conceptual example of how a minimal userscript automatically formats plain JSON text:

// ==UserScript==
// @name         Auto JSON Formatter
// @match        http://*/*
// @match        https://*/*
// @run-at       document-end
// ==/UserScript==

(function() {
    'use me strict';
    
    // Check if document contains JSON
    const bodyText = document.body.innerText.trim();
    if (!bodyText.startsWith('{') && !bodyText.startsWith('[')) return;

    try {
        const jsonObject = JSON.parse(bodyText);
        
        // Pretty-print JSON with 2-space indentation
        const formattedJSON = JSON.stringify(jsonObject, null, 2);
        
        // Render formatted text inside a <pre> block
        document.body.innerHTML = `<pre style="font-family: monospace; white-space: pre-wrap;">${formattedJSON}</pre>`;
    } catch (e) {
        // Document is not valid JSON; do nothing
    }
})();

Key Advantages of Using Userscripts for JSON

  • Customization: Unlike built-in browser viewers, userscripts allow complete control over themes, font sizes, key-sorting rules, and keyboard shortcuts.
  • Privacy: All parsing and rendering occur locally on your machine, preventing sensitive API data from being sent to third-party online JSON tools.
  • Lightweight: A custom script uses minimal system resources compared to heavy browser extensions.

Potential Conflicts to Consider

Modern web browsers like Firefox and Chrome include native JSON viewers. If a native viewer is enabled, the browser converts the page before the userscript executes. To ensure your userscript runs smoothly, you may need to disable the browser's native JSON viewing features or configure the script to target specific content headers.
