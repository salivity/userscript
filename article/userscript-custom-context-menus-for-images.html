Userscript Custom Context Menus for Images

Userscripts can create custom context menus specifically for image elements by leveraging event delegation, listening for the contextmenu event, and filtering target DOM nodes. By dynamically triggering a custom menu UI only when an <img> tag is targeted—and ensuring no active text selection exists—developers can safely enhance image interactions without disrupting standard right-click functionality or text selection elsewhere on the page.

Key Implementation Steps

To isolate context menus strictly to images without interfering with text selections or standard page elements, userscripts rely on three core principles: targeted event detection, text selection validation, and conditional event suppression.

1. Listen for Context Menu Events

Instead of attaching individual event listeners to every image, attach a single contextmenu event listener to the document. This practice, known as event delegation, efficient handle dynamically loaded images.

2. Validate the Event Target

Inside the event listener, verify that the element receiving the right-click is an image. You can check the tagName property or test against specific CSS selectors (e.g., using .closest('img') or checking background images).

3. Check for Active Text Selection

Even if a user right-clicks on an image, they might have highlighted text spanning across or near that image. Check window.getSelection().toString() to ensure no text is currently selected. If text is selected, allow the default browser context menu to open so the user can copy or search the text.

4. Conditionally Prevent Default Behavior

Call event.preventDefault() only when the target is confirmed to be an image and no text selection is active. This suppresses the browser's default context menu exclusively for the image while keeping all other right-click behavior on the website intact.

JavaScript Example

Below is a complete implementation pattern for a userscript:

// ==UserScript==
// @name         Custom Image Context Menu
// @match        *://*/*
// @grant        none
// ==UserScript==

(function () {
    'use strict';

    // Create custom menu container
    const menu = document.createElement('div');
    menu.id = 'userscript-image-menu';
    menu.style.cssText = `
        position: fixed;
        display: none;
        background: #fff;
        border: 1px solid #ccc;
        box-shadow: 2px 2px 5px rgba(0,0,0,0.2);
        z-index: 999999;
    `;
    menu.innerHTML = `<ul style="list-style: none; margin: 0; padding: 8px;">
        <li id="menu-option-1" style="cursor: pointer; padding: 4px 8px;">Custom Image Action</li>
    </ul>`;
    document.body.appendChild(menu);

    let currentTargetImage = null;

    // Listen for right-click events
    document.addEventListener('contextmenu', (e) => {
        const target = e.target;
        const selection = window.getSelection().toString();

        // Target must be an <img> and there must be no active text selection
        if (target.tagName === 'IMG' && selection.length === 0) {
            e.preventDefault(); // Suppress native context menu ONLY for images
            currentTargetImage = target;

            // Position and show the custom menu
            menu.style.left = `${e.clientX}px`;
            menu.style.top = `${e.clientY}px`;
            menu.style.display = 'block';
        } else {
            // Hide custom menu on normal right-clicks elsewhere
            menu.style.display = 'none';
        }
    });

    // Close menu when clicking anywhere else
    document.addEventListener('click', () => {
        menu.style.display = 'none';
    });

    // Handle menu option click
    document.getElementById('menu-option-1').addEventListener('click', () => {
        if (currentTargetImage) {
            console.log('Action triggered for image:', currentTargetImage.src);
        }
    });
})();

Handling Edge Cases

  • Background Images: If images are displayed via CSS background-image on <div> elements rather than <img> tags, check window.getComputedStyle(target).backgroundImage to detect them.
  • SVG and Canvas: For <svg> or <canvas> elements, update your target check logic to include SVGElement or HTMLCanvasElement.
  • Nested Images inside Links: If an image is wrapped in an <a> tag, right-clicking might still be intended for image-specific actions. Check target.closest('img') to handle images nested inside link wrappers properly.
