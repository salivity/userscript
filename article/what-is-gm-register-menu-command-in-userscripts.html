What is GM_registerMenuCommand in Userscripts?

The GM_registerMenuCommand function is an API provided by browser userscript managers—such as Tampermonkey, Violentmonkey, and Greasemonkey—that allows developers to add custom entry points to the browser extension's popup menu. By registering these commands, developers enable users to trigger specific JavaScript functions on demand rather than relying solely on automated page events. This article explains how GM_registerMenuCommand works, its syntax, required metadata permissions, and practical use cases.

Purpose and Functionality

Standard userscripts run automatically when a web page loads or updates. However, some features should only execute when requested by the user, such as opening a settings modal, triggering a manual data export, or toggling a script feature on and off.

GM_registerMenuCommand bridges this gap by adding interactive buttons or items directly inside the userscript manager's extension menu in the browser toolbar.

Syntax and Parameters

The function takes the following general syntax:

GM_registerMenuCommand(caption, onClickFunc, accessKey);

Parameters:

  1. caption (String, Required): The text displayed in the userscript manager's menu.
  2. onClickFunc (Function, Required): The callback function executed when the user clicks the menu item.
  3. accessKey (String, Optional): A single character used as a keyboard shortcut to trigger the command when the menu is open.

In modern userscript managers like Tampermonkey, an optional fourth options object or modern signature can be used to pass extra configuration, such as custom IDs or auto-close behavior.

Required Header Grant

To use this function, you must explicitly request permission in the userscript's metadata block using the @grant directive:

// ==UserScript==
// @name         Custom Menu Example
// @namespace    http://tampermonkey.net/
// @version      1.0
// @match        https://example.com/*
// @grant        GM_registerMenuCommand
// ==UserScript==

Without @grant GM_registerMenuCommand, calling the function will result in a runtime reference error.

Practical Example

Below is a basic implementation demonstrating how to add a toggle switch for a script setting:

// ==UserScript==
// @name         Page Theme Dynamic Toggle
// @match        *://*/*
// @grant        GM_registerMenuCommand
// ==UserScript==

(function() {
    'use strict';

    function toggleDarkMode() {
        document.body.classList.toggle('dark-mode-override');
        alert('Dark mode toggled!');
    }

    // Register the command in the extension menu
    GM_registerMenuCommand("Toggle Dark Mode", toggleDarkMode, "d");
})();

When a user clicks on the extension icon while visiting any site, "Toggle Dark Mode" will appear as a clickable option under this script's section.

Common Use Cases

  • Configuration Modals: Opening a user interface to let users change script preferences.
  • Feature Toggles: Enabling or disabling specific script functions without editing code.
  • Manual Data Processing: Initiating actions like downloading data, scraping content, or filling forms on demand.
  • Debugging Tools: Dumping diagnostic data to the browser console when troubleshooting.

Unregistering Menu Commands

Some userscript managers also support GM_unregisterMenuCommand. This companion function allows developers to remove menu items dynamically using a menu command ID returned by GM_registerMenuCommand, which is useful for updating menu text state dynamically (e.g., changing "Enable Feature" to "Disable Feature").
