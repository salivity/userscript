How to Bundle CSS Frameworks into Userscripts

Bundling CSS frameworks like Tailwind CSS or Bootstrap into browser userscripts allows developers to quickly build modern, styled user interfaces on top of existing websites. The core process involves setting up a module bundler, compiling the framework's CSS into JavaScript strings, and injecting the resulting styles into the web page—ideally using Shadow DOM to prevent style leakage between the host site and your custom UI.

Step 1: Set Up a Module Bundler

Standard userscripts consist of a single JavaScript file, but modern CSS frameworks rely on preprocessors like PostCSS or Sass. To use them, you must set up a build system like Vite, Webpack, or Rollup. Using build tools specifically configured for userscript development (such as vite-plugin-userscript) helps automatically handle headers and bundle single-file outputs.

Step 2: Configure the CSS Framework

Install and configure the framework within your build pipeline:

  • Tailwind CSS: Install Tailwind and PostCSS. Configure tailwind.config.js to purge unused CSS by setting the content path to point to your script's source files. Import Tailwind directives into your main CSS file.
  • Bootstrap: Install Bootstrap via NPM. Import Bootstrap's SCSS or compiled CSS directly into your project's entry file.

Step 3: Import CSS as Inline Strings

To inject styles directly via JavaScript, configure your bundler to import CSS as raw strings rather than extracting them into a separate .css file.

  • In Vite, append ?inline to your CSS import: import cssText from './style.css?inline';
  • In Webpack, use css-loader with the exportType: 'string' option or raw-loader.

Step 4: Inject Styles into the Webpage

Once the CSS is stored in a JavaScript string variable, inject it into the document DOM when the userscript runs. You can accomplish this through two main approaches:

Option A: Standard DOM Injection

Create a <style> element, populate it with your CSS string, and append it to the document head:

const style = document.createElement('style');
style.textContent = cssText;
document.head.appendChild(style);

Option B: Tampermonkey API

Declare @grant GM_addStyle in your userscript's metadata block and pass the CSS string to the API:

// ==UserScript==
// @name         Custom UI Script
// @grant        GM_addStyle
// ==UserScript==

GM_addStyle(cssText);

Step 5: Prevent Style Leakage with Shadow DOM

Global resets from frameworks—such as Tailwind’s Preflight or Bootstrap’s Reboot—can easily alter or ruin the host website's layout. Simultaneously, the host site's CSS can corrupt your userscript's UI.

To guarantee complete CSS isolation:

  1. Create a host container element on the page.
  2. Attach a Shadow Root to the container: const shadow = container.attachShadow({ mode: 'open' });
  3. Append a <style> tag containing your compiled CSS string directly inside the shadow root.
  4. Render your userscript's HTML interface inside the shadow root.

Encapsulating your framework inside a Shadow DOM ensures that both your userscript UI and the host webpage remain visually isolated from one another.
