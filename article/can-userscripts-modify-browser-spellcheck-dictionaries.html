Can Userscripts Modify Browser Spellcheck Dictionaries?

Userscripts cannot directly modify or add custom jargon to a browser's native spellchecker dictionary. Due to strict browser security models and sandboxing, JavaScript running within the page context lacks permission to access or alter OS-level and browser-level spellcheck engines. However, developers and users can achieve custom spellchecking functionality for industry-specific terminology using alternative methods like custom JavaScript spellchecking libraries, browser extensions, or native browser dictionary settings.

Why Userscripts Cannot Access Native Dictionaries

Modern web browsers separate web content execution from core browser functionality to protect user privacy and system security. Userscripts execute inside the context of the Document Object Model (DOM) or a sandbox closely tied to web pages.

The native spellchecker (such as Chromium’s Hunspell or native OS engines) operates at a higher privilege level within the browser architecture. Browsers do not expose a web API—or even a UserScript manager API like Tampermonkey or Violentmonkey—that allows JavaScript to programmatically inject words into the browser's internal spellcheck="true" dictionary.

Alternative Solutions for Industry-Specific Jargon

While a userscript cannot alter the native dictionary, several workarounds exist to handle specialized vocabulary:

1. Custom JavaScript Spellcheck Overlays

A userscript can disable the native spellchecker on input fields (spellcheck="false") and replace it with a custom client-side spellchecking library, such as Typo.js.

Through this approach, the script can:

  • Load a custom dictionary file containing technical terms, medical jargon, or company-specific acronyms.
  • Highlight misspelled words using custom DOM overlays or rich text editors.
  • Render a custom context menu suggesting corrections based on the custom dataset.

2. Manual Native Dictionary Additions

For individual users, the simplest native solution is adding words directly to the browser's custom dictionary:

  • Chrome/Edge: Navigate to Settings > Languages > Customize spell check, where custom words can be added manually or imported via text lists.
  • Firefox: Right-click a word highlighted as misspelled in any text field and select Add to Dictionary.

3. Browser Extensions vs. Userscripts

While userscripts are restricted, dedicated Browser Extensions (WebExtensions) have access to broader browser APIs. Although WebExtensions still face limits regarding direct modification of native dictionary files on some platforms, they offer deeper DOM integration and can streamline side-loading custom language packs or managing enterprise-wide dictionary policies via administrative templates.
