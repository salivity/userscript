Auto Collapse Boilerplate Code on Stack Overflow

Yes, userscripts can automatically collapse repetitive boilerplate code on Stack Overflow to improve readability and streamline your browsing experience. By using popular browser extensions like Tampermonkey, Violentmonkey, or Greasemonkey, custom JavaScript can run on Stack Overflow pages to detect code blocks, check their length or content, and automatically hide or collapse them behind a toggle button.

How Userscripts Handle Stack Overflow Code Blocks

Userscripts interact directly with the Document Object Model (DOM) of a webpage after it loads. On Stack Overflow, code snippets are usually contained within <pre><code> elements. A userscript can scan these elements and manipulate them based on specific rules you define.

Key Capabilities of a Code-Collapsing Userscript

  • Height-Based Collapsing: Set a maximum height threshold (e.g., 200 pixels). Any code block exceeding this limit is automatically capped, adding a scrollbar or a "Show More" button.
  • Pattern Matching: Scan the text inside code blocks for specific repetitive imports, config files, or standard boilerplate (such as long JSON payloads or standard HTML templates) and hide those specific blocks by default.
  • Interactive Toggles: Insert a small button above or inside the code block allowing you to expand or collapse the content instantly with a single click.

Example: Building a Basic Boilerplate Collapser

You can write or install a simple script to handle large or repetitive code blocks automatically. Below is the structural logic used by such userscripts:

// ==UserScript==
// @name         Stack Overflow Code Auto-Collapser
// @namespace    http://tampermonkey.net/
// @version      1.0
// @description  Collapse long boilerplate code blocks on Stack Overflow
// @match        https://stackoverflow.com/questions/*
// @grant        none
// ==UserScript==

(function() {
    'use strict';

    // Maximum height in pixels before collapsing
    const MAX_HEIGHT = 200;

    // Target all code pre blocks on the page
    const codeBlocks = document.querySelectorAll('pre');

    codeBlocks.forEach(block => {
        if (block.clientHeight > MAX_HEIGHT) {
            // Apply initial collapsed state
            block.style.maxHeight = MAX_HEIGHT + 'px';
            block.style.overflow = 'hidden';
            block.style.position = 'relative';

            // Create a toggle button
            const button = document.createElement('button');
            button.innerText = 'Expand Code';
            button.style.cssText = 'display: block; margin-bottom: 5px; cursor: pointer;';

            // Toggle logic
            button.addEventListener('click', () => {
                if (block.style.maxHeight) {
                    block.style.maxHeight = '';
                    button.innerText = 'Collapse Code';
                } else {
                    block.style.maxHeight = MAX_HEIGHT + 'px';
                    button.innerText = 'Expand Code';
                }
            });

            block.parentNode.insertBefore(button, block);
        }
    });
})();

Existing Options and Alternatives

If you prefer not to write your own script, pre-made userscripts are available on repositories like Greasy Fork and OpenUserJS. Searching for keywords like "StackOverflow auto collapse code" or "StackOverflow code toggle" yields community-maintained scripts that include advanced features, such as remembering your preferences or automatically recognizing specific language imports.
