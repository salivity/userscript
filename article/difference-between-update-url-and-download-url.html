Difference Between @updateURL and @downloadURL

In userscripts, @updateURL and @downloadURL are metadata directives used by script managers like Tampermonkey, Violentmonkey, and Greasemonkey to automate script updates. While both work together to keep userscripts up to date, @updateURL is used exclusively to check if a new version is available, whereas @downloadURL defines the location from which the full updated script is downloaded.

Understanding @updateURL

The @updateURL tag tells the userscript manager where to check for script updates. When the script manager performs a background check, it requests the URL specified in this tag.

Key characteristics:

  • Purpose: Checks whether a new version exists.
  • Content: It ideally points to a file containing only the meta block (the header section between ==UserScript== and ==/UserScript==).
  • Efficiency: Pointing to a meta-block file saves bandwidth because the manager only needs to download a few lines of text to read the @version field rather than the full source code.

Understanding @downloadURL

The @downloadURL tag defines the exact URL where the complete, updated userscript source code (.user.js) is hosted.

Key characteristics:

  • Purpose: Provides the full script content for installation.
  • Content: Points to the entire userscript file.
  • Trigger: It is requested only after an update check determines that a newer version is available.

Core Differences

  • Function: @updateURL checks for updates; @downloadURL downloads the update.
  • Execution Order: The manager calls @updateURL first. If a newer @version string is detected, it then calls @downloadURL.
  • Bandwidth Usage: @updateURL is designed to be lightweight, while @downloadURL transfers the entire script payload.

Fallback Behaviors

Userscript managers handle missing tags gracefully:

  • Only @downloadURL specified: The manager uses the @downloadURL to both check for updates and download the source code.
  • Only @updateURL specified: The manager checks @updateURL for updates and uses that same URL to download the entire updated script if a newer version is found.
