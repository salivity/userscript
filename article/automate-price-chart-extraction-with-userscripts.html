Automate Price Chart Extraction with Userscripts

Userscripts offer a powerful, lightweight solution for automatically extracting historical price charts and underlying financial data directly from web portals. By running custom JavaScript inside browser extensions like Tampermonkey or Violentmonkey, these scripts can bypass tedious manual data entry by capturing raw visual or network data. This article explains how userscripts execute this automation through DOM manipulation, network request interception, data parsing, and automated file downloads.

1. Browser-Level Script Injection

Userscripts operate by injecting custom JavaScript into specified web domains when a page loads. Unlike standard browser developer tools that require manual execution, a userscript extension automatically triggers the code based on @match URL rules. Once injected, the script runs within the context of the active webpage, granting it full access to the page's Document Object Model (DOM), local storage, and global JavaScript window objects.

2. Network Request Interception (API Capture)

Modern financial portals rarely render historical price charts purely in static HTML. Instead, the page loads a framework, which then issues asynchronous fetch or XMLHttpRequest (XHR) calls to back-end APIs to retrieve JSON or CSV time-series data (Open, High, Low, Close, Volume).

Userscripts automate extraction most efficiently by intercepting these network calls before the data is even rendered:

  • Monkey-Patching: The script overrides the native window.fetch or XMLHttpRequest.prototype.open methods on page load.
  • Payload Capture: When the financial portal requests chart data, the intercepted function reads the raw response payload in the background.
  • Data Extraction: The script extracts the exact time-series arrays without relying on visible web elements, ensuring 100% data accuracy.

3. DOM Scraping and Canvas Data Extraction

If network interception is blocked or obfuscated, userscripts fall back on direct DOM scraping or visual element parsing:

  • SVG and HTML Tables: For charts rendered as Scalable Vector Graphics (SVG) or rendered tables, the script queries DOM elements (e.g., document.querySelectorAll('g.chart-node')) to extract coordinate values and date markers, mapping them back to price scales.
  • Canvas Element State: HTML5 <canvas> charts do not expose structural HTML child nodes. In these cases, userscripts simulate mouse move events across the canvas element to trigger interactive tooltips, reading price and date values directly from the dynamic tooltip DOM nodes as they pop up.

4. Data Processing and Automated Export

Once the historical data points are captured—either via intercepted API payloads or DOM scraping—the userscript converts the raw arrays into structured formats like CSV or JSON.

To complete the automation loop, the script creates an in-memory data URL using URL.createObjectURL(new Blob([data])) and dynamically attaches a hidden HTML <a> element to the page. It then programmatically triggers a .click() event on the link, forcing the browser to instantly download the historical chart data directly to the user's local device without any manual intervention.
