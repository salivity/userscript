What Is the Userscripts App for iOS Safari?

The Userscripts app for iOS Safari is a free, open-source browser extension that enables users to execute custom JavaScript code on web pages. Functioning similarly to desktop extensions like Tampermonkey or Greasemonkey, it allows iPhone and iPad users to modify website layouts, automate repetitive tasks, block undesirable content, and add missing features to web applications directly within the mobile Safari browser.

Core Functionality of Userscripts on iOS

Safari on iOS historically lacked support for client-side script modification. The Userscripts app solves this by acting as a manager that integrates directly into Safari's native extension system on iOS and iPadOS.

Webpage Customization

Userscripts can alter the CSS and HTML of any website after it loads. This allows users to:

  • Force dark mode on websites that do not natively support it.
  • Modify font sizes, page margins, and visual themes for better readability.
  • Hide intrusive UI elements, sticky headers, or sidebars.

Workflow Automation

The app allows users to run scripts that streamline daily online tasks:

  • Automatically skip video ads or countdown timers where supported.
  • Auto-fill recurring web forms and bypass repetitive prompts.
  • Automatically expand collapsed comment sections or text blocks.

Feature Enhancement

By adding custom scripts, users can introduce desktop-like capabilities to mobile web browsing:

  • Enable video playback controls, such as custom playback speeds or picture-in-picture mode, on restricted sites.
  • Add direct download links for media files.
  • Integrate third-party utilities, such as word counters or translation overlays, into specific web tools.

Key Technical Features

  • Open-Source and Private: Userscripts operates locally on your device. It does not track user activity or send data to external servers, and the source code is publicly auditable.
  • Standard .user.js Support: It supports standard user script formats, allowing full compatibility with thousands of community-built scripts available on public repositories.
  • Local Storage Integration: Scripts are managed directly using the iOS Files app, making it easy to sync, edit, backup, or import custom JavaScript files across devices.
  • Domain-Specific Control: Users can grant or restrict script permissions on a per-website basis directly from the Safari toolbar menu.
