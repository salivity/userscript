How to Translate HTML Attributes Using Userscripts

Yes, userscripts can automatically translate specific HTML attributes such as title, alt, placeholder, and aria-label on any web page. By running custom JavaScript through browser extensions like Tampermonkey, Violentmonkey, or Greasemonkey, you can target DOM elements, extract their attribute values, pass the text to a translation service or local dictionary, and replace the original attribute value with the translated text.

How Userscripts Target HTML Attributes

Targeting HTML attributes requires selecting elements that contain text-bearing attributes. Standard JavaScript methods like document.querySelectorAll() allow you to find all elements with specific attributes across a document.

For example, to find all elements with title or alt attributes:

const elementsWithTitle = document.querySelectorAll('[title]');
const elementsWithAlt = document.querySelectorAll('[alt]');

Once selected, you can access and modify attributes directly using .getAttribute() and .setAttribute(), or via direct property access (element.title or element.alt).

Translation Approaches

There are two primary ways to translate attribute content using a userscript:

1. Dictionary Mapping (Static Translation)

If you are translating repetitive user interfaces or specific fixed text, a local dictionary object provides the fastest performance without relying on external APIs.

const translationMap = {
  "Submit Form": "Formular absenden",
  "User Avatar": "Benutzer-Avatar",
  "Close Window": "Fenster schließen"
};

document.querySelectorAll('[title], [alt]').forEach(el => {
  ['title', 'alt'].forEach(attr => {
    const value = el.getAttribute(attr);
    if (value && translationMap[value]) {
      el.setAttribute(attr, translationMap[value]);
    }
  });
});

2. External API Integration (Dynamic Translation)

For unknown or dynamic content, userscripts can send the attribute text to public or self-hosted translation APIs (such as DeepL, Google Translate, or LibreTranslate).

Using the userscript manager's cross-origin request function (GM_xmlhttpRequest or GM.xmlHttpRequest), you can send the attribute string to an API endpoint and update the attribute once the response returns.

function translateAttribute(element, attributeName) {
  const originalText = element.getAttribute(attributeName);
  if (!originalText) return;

  // Example request structure using GM_xmlhttpRequest
  GM_xmlhttpRequest({
    method: "POST",
    url: "https://api.example-translator.com/translate",
    headers: { "Content-Type": "application/json" },
    data: JSON.stringify({ text: originalText, target_lang: "ES" }),
    onload: function(response) {
      const data = JSON.parse(response.responseText);
      if (data.translatedText) {
        element.setAttribute(attributeName, data.translatedText);
      }
    }
  });
}

Handling Dynamic Content with MutationObserver

Modern web applications frequently load content dynamically using AJAX or single-page application (SPA) frameworks. A userscript that only runs once when the page loads will miss attributes added later.

To resolve this, use a MutationObserver to watch the DOM for newly added nodes or attribute changes:

const observer = new MutationObserver(mutations => {
  mutations.forEach(mutation => {
    mutation.addedNodes.forEach(node => {
      if (node.nodeType === Node.ELEMENT_NODE) {
        // Target elements within newly inserted DOM trees
        const elements = node.querySelectorAll ? node.querySelectorAll('[title], [alt]') : [];
        elements.forEach(el => {
          // Perform translation logic here
        });
      }
    });
  });
});

observer.observe(document.body, { childList: true, subtree: true });

Key Considerations

  • Performance: Translating hundreds of attributes via external API calls can hit rate limits or cause latency. Batching API requests or caching translated strings locally via GM_setValue is recommended.
  • Attribute Types: Remember to target secondary accessibility attributes like aria-label, aria-roledescription, and form control attributes like placeholder alongside standard title and alt tags.
  • Tooltips: Some custom UI tooltips do not use the native HTML title attribute, relying instead on data-* attributes (e.g., data-tooltip). Inspect the page structure to ensure you target the correct attribute names.
