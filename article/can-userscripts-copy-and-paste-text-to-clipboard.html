Can Userscripts Copy and Paste Text to Clipboard?

Userscripts can interact with the system clipboard to copy and paste text using modern browser Web APIs or specialized userscript manager APIs. While reading and writing clipboard data enables useful browser automation features, modern browser security standards require explicit user interactions or specific script configurations to prevent unauthorized access to sensitive user data.

Writing to the Clipboard (Copying Text)

Copying text to the clipboard from a userscript is straightforward and can be accomplished in two primary ways:

  1. Using Userscript Manager APIs: Popular userscript managers like Tampermonkey, Violentmonkey, and Greasemonkey provide dedicated functions to bypass standard web page limitations. By adding @grant GM_setClipboard to the script header, you can use the function directly:

    GM_setClipboard("Text to copy", "text");

    This method is highly reliable because it runs with extension-level permissions and does not always require direct user interaction on the active webpage.

  2. Using the Standard Web Async Clipboard API: You can also use standard JavaScript available to regular web pages:

    navigator.clipboard.writeText("Text to copy");

    This modern method works asynchronously and returns a Promise. However, browsers generally require the page to be served over HTTPS and may require the action to be triggered by a user gesture, such as a button click.

Reading from the Clipboard (Pasting Text)

Reading clipboard contents is strictly regulated by web browsers to protect user privacy, such as preventing scripts from silently stealing copied passwords or private notes.

  1. Using navigator.clipboard.readText(): Userscripts can request text from the clipboard using the standard web API:

    navigator.clipboard.readText().then(text => {
    console.log("Clipboard content:", text);
});

    When executed, the browser will display a permission prompt asking the user to allow the website to read clipboard data. Additionally, this function must usually be called inside an event listener triggered by a user action, such as a click or key press.

  2. Listening for Paste Events: Alternatively, a userscript can intercept standard paste actions performed by the user by listening to the paste event on the document or a specific input field:

    document.addEventListener('paste', (event) => {
    let pastedData = event.clipboardData.getData('text');
    console.log("Pasted text:", pastedData);
});

Essential Requirements and Security Limitations

  • User Gestures: Most modern browsers block clipboard reading and writing if the script attempts it automatically without a direct user interaction (like clicking a custom button created by the script).
  • Secure Contexts (HTTPS): Standard Clipboard Web APIs only function in secure contexts (https://).
  • Active Tab Focus: The web page running the userscript must typically be the active, focused browser tab for clipboard operations to succeed.
