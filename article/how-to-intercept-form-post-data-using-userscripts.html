How to Intercept Form POST Data Using Userscripts

Yes, userscripts can intercept and rewrite outgoing form POST data before submission to a server. Depending on whether a web page sends data using a standard HTML form element or modern asynchronous JavaScript requests (such as AJAX or the Fetch API), userscripts can capture and modify the payload by listening to DOM submission events or by overriding native browser networking functions.

Intercepting Standard HTML Form Submissions

For traditional web forms that trigger standard browser navigation on submit, a userscript can hook into the DOM submit event using event capturing to rewrite form inputs before submission occurs.

// Register event listener in the capture phase to run before site scripts
document.addEventListener('submit', function(event) {
    const form = event.target;
    
    // Check if it's the target form
    if (form.matches('#targetForm')) {
        // Option 1: Directly alter existing input elements
        const input = form.querySelector('input[name="example"]');
        if (input) {
            input.value = 'rewrittenValue';
        }

        // Option 2: Add new hidden inputs to the form
        const hiddenInput = document.createElement('input');
        hiddenInput.type = 'hidden';
        hiddenInput.name = 'extraParam';
        hiddenInput.value = 'customData';
        form.appendChild(hiddenInput);
    }
}, true);

Intercepting Asynchronous POSTs via Fetch API

Modern websites often process forms using fetch(). A userscript can override window.fetch (or unsafeWindow.fetch in browser extension managers) to inspect and rewrite request payloads before execution.

const originalFetch = unsafeWindow.fetch;

unsafeWindow.fetch = async function(resource, config) {
    if (config && config.method && config.method.toUpperCase() === 'POST') {
        // Rewrite JSON payloads
        if (typeof config.body === 'string') {
            try {
                let payload = JSON.parse(config.body);
                payload.targetField = 'newPayloadValue';
                config.body = JSON.stringify(payload);
            } catch (e) {
                // Body is not valid JSON (e.g., URL-encoded string)
            }
        }
        
        // Rewrite FormData payloads
        else if (config.body instanceof FormData) {
            config.body.set('targetField', 'newPayloadValue');
        }
    }
    
    return originalFetch.call(this, resource, config);
};

Intercepting Asynchronous POSTs via XMLHttpRequest (XHR)

Legacy or framework-based web pages may use XMLHttpRequest. Userscripts can override XMLHttpRequest.prototype.send to modify POST data.

const originalSend = unsafeWindow.XMLHttpRequest.prototype.send;

unsafeWindow.XMLHttpRequest.prototype.send = function(body) {
    if (body && typeof body === 'string') {
        // Intercept and alter URL-encoded string data
        let params = new URLSearchParams(body);
        if (params.has('fieldToChange')) {
            params.set('fieldToChange', 'updatedValue');
            body = params.toString();
        }
    }
    
    return originalSend.call(this, body);
};

Critical Requirements for Userscript Interception

  • Execution Timing: Set @run-at document-start in the userscript header to guarantee that network overrides run before the target webpage executes its scripts.
  • Context Isolation: When modifying global objects like fetch or XMLHttpRequest in engine environments such as Tampermonkey or Violentmonkey, modify unsafeWindow.fetch and unsafeWindow.XMLHttpRequest instead of window to apply changes directly to the page script context.
