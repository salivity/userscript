How Userscripts Capture and Redirect Console Logs

Userscripts capture and redirect console.log output to a custom graphical UI by overriding the native console.log function—a technique known as monkey patching—and sending the intercepted arguments to a custom DOM element injected into the webpage. By preserving the original console method while simultaneously formatting and appending logs to a custom overlay, userscripts allow developers to inspect debug messages directly on the page without opening browser developer tools.

Step 1: Monkey Patching the Console Method

To capture log messages, the userscript must store a reference to the browser's native console.log method and then replace console.log with a custom function. This ensures that existing page scripts and userscripts trigger the custom behavior whenever console.log() is called.

// Store the original console.log function
const originalLog = console.log;

// Override console.log
console.log = function (...args) {
    // 1. Call the original console.log to keep native browser logging intact
    originalLog.apply(console, args);

    // 2. Pass the arguments to the custom UI renderer
    renderToCustomUI(args);
};

If you need to capture logs generated by the host website's scripts (and not just the userscript context), target unsafeWindow.console.log instead of window.console.log.

Step 2: Creating and Injecting the Graphical UI

The script creates an HTML container (such as a <div>) using JavaScript, applies CSS styles to anchor it to the viewport, and appends it to the DOM.

// Create the log container UI
const logUI = document.createElement('div');
logUI.id = 'custom-console-ui';
Object.assign(logUI.style, {
    position: 'fixed',
    bottom: '10px',
    right: '10px',
    width: '400px',
    height: '200px',
    backgroundColor: 'rgba(0, 0, 0, 0.85)',
    color: '#00ff00',
    fontFamily: 'monospace',
    fontSize: '12px',
    padding: '10px',
    overflowY: 'auto',
    zIndex: '999999',
    borderRadius: '5px',
    boxShadow: '0 0 10px rgba(0,0,0,0.5)'
});

// Append to document body or documentElement
(document.body || document.documentElement).appendChild(logUI);

Step 3: Formatting Arguments and Appending to UI

Received arguments can range from simple strings and numbers to complex objects, arrays, or errors. The function handling the UI update processes these arguments, converts non-string data into readable formats using JSON.stringify(), and creates visible log entries.

function renderToCustomUI(args) {
    const messageLine = document.createElement('div');
    messageLine.style.borderBottom = '1px solid #333';
    messageLine.style.padding = '2px 0';

    // Format complex objects and join arguments
    const formattedMessage = args.map(arg => {
        if (typeof arg === 'object' && arg !== null) {
            try {
                return JSON.stringify(arg, null, 2);
            } catch (e) {
                return '[Unserializable Object]';
            }
        }
        return String(arg);
    }).join(' ');

    messageLine.textContent = `> ${formattedMessage}`;
    logUI.appendChild(messageLine);

    // Automatically scroll to the newest message
    logUI.scrollTop = logUI.scrollHeight;
}

Key Considerations for Userscript Implementations

  • Execution Timing: Set @run-at document-start in the userscript metadata block if you need to catch console logs that fire immediately while the page is loading.
  • Handling Circular References: Standard JSON.stringify() fails on objects with circular references. Use a custom stringifier or standard String() fallback to prevent UI crashes.
  • Performance: High-frequency logging can overload DOM performance. Limit the maximum number of displayed entries by removing older child nodes when the log count exceeds a set threshold (e.g., keeping only the last 100 entries).
