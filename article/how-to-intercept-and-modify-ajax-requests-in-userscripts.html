How to Intercept and Modify AJAX Requests in Userscripts

Yes, userscripts can intercept and modify form data parameters submitted via AJAX before the request is sent to the server. Because userscripts run directly in the browser environment with access to the DOM and JavaScript execution context, they can hook into native networking APIs like XMLHttpRequest and fetch. By monkey-patching these built-in browser functions, a userscript can inspect, edit, add, or remove form parameters dynamically.

Intercepting XMLHttpRequest (XHR)

To intercept legacy or standard XHR AJAX requests, a userscript can override the XMLHttpRequest.prototype.send method. By inspecting the body passed to send, the script can modify FormData objects, URL-encoded strings, or JSON payloads before standard execution continues.

// Preserve the original send method
const originalSend = XMLHttpRequest.prototype.send;

XMLHttpRequest.prototype.send = function(body) {
    // Check if the payload is an instance of FormData
    if (body instanceof FormData) {
        // Modify an existing parameter or add a new one
        body.set('username', 'modifiedValue');
        body.append('extraField', 'injectedData');
    } else if (typeof body === 'string') {
        // Handle URL-encoded or JSON strings
        try {
            let data = JSON.parse(body);
            data.username = 'modifiedValue';
            body = JSON.stringify(data);
        } catch (e) {
            // Handle standard query strings (e.g., key1=val1&key2=val2)
            let params = new URLSearchParams(body);
            params.set('username', 'modifiedValue');
            body = params.toString();
        }
    }

    // Call the original send method with the modified body
    return originalSend.call(this, body);
};

Intercepting the fetch API

Modern websites often use the fetch API for asynchronous requests. Userscripts can intercept these calls by replacing window.fetch with a custom wrapper function.

// Preserve the original fetch function
const originalFetch = window.fetch;

window.fetch = async function(...args) {
    let [resource, config] = args;

    if (config && config.body) {
        if (config.body instanceof FormData) {
            // Alter parameters inside FormData
            config.body.set('email', 'newemail@example.com');
        } else if (typeof config.body === 'string') {
            // Alter JSON payloads
            try {
                let data = JSON.parse(config.body);
                data.email = 'newemail@example.com';
                config.body = JSON.stringify(data);
            } catch (e) {
                // Not JSON, continue without modification
            }
        }
    }

    // Execute the original fetch request with modified configuration
    return originalFetch.apply(this, [resource, config]);
};

Key Considerations for Userscript Execution

  • Execution Timing: The userscript must run early enough to patch XMLHttpRequest or fetch before the target web page stores references to the original native functions. Setting @run-at document-start in the userscript metadata block ensures the script executes before page scripts load.
  • Sandbox & unsafeWindow: Popular userscript managers (such as Tampermonkey or Violentmonkey) isolate script execution contexts. If the web page executes AJAX calls within its own context, accessing and modifying the page's native functions may require using unsafeWindow.XMLHttpRequest and unsafeWindow.fetch instead of global window objects.
