Can Userscripts Modify window.print Headers?

Userscripts can alter what appears in the printed output triggered by window.print(), but they cannot directly control the browser's native print dialog interface. Due to browser security restrictions, JavaScript running on a page cannot toggle settings inside the browser's printing window. However, a userscript can modify the web page's DOM and inject CSS print stylesheets to remove website navigation headers, hide unwanted elements, and suppress browser-generated header and footer margins before the print command executes.

Web Page Headers vs. Browser UI Headers

To understand what a userscript can modify, it is essential to distinguish between two types of headers:

  1. In-Page Navigation Headers: HTML elements such as <header>, <nav>, fixed banners, and top menu bars defined by the website.
  2. Browser Print Headers: Native headers added by the browser during printing, such as the date, page title, URL, and page numbers.

Userscripts have full control over in-page navigation headers, but indirect control over native browser print headers.

Stripping In-Page Navigation Headers

If your goal is to prevent website menus, headers, and site navigation from appearing on the printed page, userscripts are fully capable of achieving this. A userscript can inject @media print CSS rules into the document head to hide these elements dynamically before window.print() runs.

Example Userscript CSS Injection

// ==UserScript==
// @name         Remove Print Navigation Headers
// @match        https://example.com/*
// @run-at       document-start
// ==UserScript==

(function() {
    'use strict';

    const style = document.createElement('style');
    style.textContent = `
        @media print {
            /* Hide HTML navigation, headers, and sidebars */
            header, nav, .navbar, .navigation, .site-header {
                display: none !important;
            }
        }
    `;
    document.head.appendChild(style);
})();

By injecting this stylesheet, the specified navigation elements will automatically disappear as soon as window.print() is called or when the user opens the print dialog.

Suppressing Native Browser Headers and Footers

The checkboxes for "Headers and footers" inside the browser's print dialog UI cannot be clicked or toggled automatically via JavaScript. However, userscripts can hide browser-generated headers (such as the URL, date, and document title) using the CSS @page rule.

By setting the print margin to zero, most modern browsers (including Chrome, Edge, and Firefox) will automatically suppress native headers and footers.

CSS Solution for Native Headers

@media print {
    @page {
        margin: 0; /* Suppresses browser native headers and footers */
    }
    body {
        margin: 1.5cm; /* Re-applies margin to content so text isn't cut off */
    }
}

A userscript can append this CSS to any target site to ensure native headers and footers are stripped without requiring the user to manually uncheck options in the print dialog.

Summary

  • Native Print Dialog UI: Userscripts cannot programmatically alter settings inside the browser's print dialog pop-up.
  • On-Page Navigation Headers: Userscripts can hide site navigation, headers, and footers using @media print CSS rules.
  • Browser-Generated Headers/Footers: Userscripts can hide native browser headers in most modern browsers by injecting @page { margin: 0; } into the page styling.
