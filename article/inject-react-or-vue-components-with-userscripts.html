Inject React or Vue Components with Userscripts

Userscripts can successfully inject modern React or Vue components directly into the Document Object Model (DOM) of legacy websites. By creating a dedicated container element within the target site's layout, developers can mount full-fledged modern frontend components using managers like Tampermonkey or Violentmonkey. This approach allows developers to modernize user interfaces, add complex features, or streamline workflows on older web applications without altering the underlying server-side codebase.

How Component Injection Works

Injecting a modern framework component into a legacy page relies on standard DOM manipulation combined with the framework's mounting API. The basic process follows three core steps:

  1. Create an Anchor Container: The userscript creates a new HTML element (usually a div) and appends it to a specific location in the legacy site's DOM.
  2. Load Framework Libraries: React or Vue dependencies are included either by bundling them into the userscript or by importing them dynamically via userscript metadata headers (@require).
  3. Mount the Application: The framework’s render engine targets the newly created container element to initialize the component tree.

Basic React Example

// Create and insert container
const container = document.createElement('div');
container.id = 'my-custom-react-root';
document.body.appendChild(container);

// Mount React Component
const root = ReactDOM.createRoot(container);
root.render(React.createElement(MyComponent));

Basic Vue Example

// Create and insert container
const container = document.createElement('div');
container.id = 'my-custom-vue-root';
document.body.appendChild(container);

// Mount Vue Component
const app = Vue.createApp(MyComponent);
app.mount('#my-custom-vue-root');

Recommended Architecture: Modern Bundlers

While inline scripts using CDN-hosted packages work, building complex components is best handled using a bundler such as Vite, Webpack, or Rollup.

Using modern tooling provides several benefits:

  • JSX and Single File Components (SFCs): Write UI using native React JSX or Vue .vue files.
  • Single File Output: Configure the bundler to compile all JavaScript, framework runtime code, and assets into a single .user.js file.
  • Inline CSS: Transform imported CSS files into style strings injected directly into the document head or a Shadow DOM.

Plugins like vite-plugin-monkey simplify this setup by automatically handling userscript headers, hot module replacement (HMR) during development, and single-file production builds.

Critical Technical Considerations

1. Style Isolation (Preventing CSS Collisions)

Legacy websites often use global CSS rules that can leak into and break modern components. Conversely, component styles might disrupt the host site's formatting.

To fix this, attach a Shadow DOM to the injected container and mount the framework root inside it:

const hostContainer = document.createElement('div');
document.body.appendChild(hostContainer);

// Create a closed or open shadow root
const shadowRoot = hostContainer.attachShadow({ mode: 'open' });

// Create the target mount point inside the shadow root
const mountPoint = document.createElement('div');
shadowRoot.appendChild(mountPoint);

// Mount component inside the shadow root
const root = ReactDOM.createRoot(mountPoint);
root.render(React.createElement(MyComponent));

2. Handling Asynchronous DOM Loading

Legacy sites frequently render elements dynamically via old AJAX patterns or jQuery. If the target insertion point is not present when the userscript runs, the injection will fail.

Use a MutationObserver or utility functions to wait for the target host element to appear in the DOM before appending the component container.

3. Execution Context and Permissions

Userscripts run in an isolated sandbox. If the component needs to interact directly with variables in the legacy page's window object, adjust the @grant directives in the userscript header or access page globals via unsafeWindow.
