Can Userscripts Modify XML Loaded by Webpages?

Userscripts can fully parse, modify, and manipulate XML documents loaded by a webpage. By leveraging browser APIs such as DOMParser and XMLSerializer alongside userscript network interception techniques, scripts can capture XML data before or after it loads, alter its nodes and attributes, and feed the modified XML back to the webpage or display it directly.

Intercepting and Accessing XML Data

Webpages generally load XML files using the Fetch API or XMLHttpRequest (XHR). Userscripts can access this data in two primary ways:

  1. Monkey-patching Network Requests: A userscript can override window.fetch or XMLHttpRequest.prototype.open to intercept outgoing requests and inspect or alter incoming XML responses before the webpage processes them.
  2. Direct Fetching: Userscripts can independently fetch XML resources using standard JavaScript tools or userscript-specific functions like GM_xmlhttpRequest, which bypasses same-origin policies (CORS).

Parsing XML with DOMParser

Once the raw XML text is retrieved, the browser's native DOMParser API converts the XML string into an actionable DOM structure:

const parser = new DOMParser();
const xmlDoc = parser.parseFromString(xmlText, "text/xml");

This creates an XML Document object, allowing the script to traverse nodes using standard DOM methods like querySelector, querySelectorAll, or getElementsByTagName.

Modifying the XML Structure

With the XML parsed into a DOM object, standard JavaScript DOM manipulation methods work directly on the elements:

  • Updating Content: node.textContent = "New Value"
  • Changing Attributes: node.setAttribute("status", "active")
  • Adding Nodes: xmlDoc.createElement("newTag") combined with appendChild() or insertBefore()
  • Removing Nodes: node.remove() or parentNode.removeChild(node)

Serializing and Re-injecting the XML

After completing the modifications, the XML document can be converted back into a string using XMLSerializer:

const serializer = new XMLSerializer();
const modifiedXmlText = serializer.serializeToString(xmlDoc);

The resulting string can be injected into the DOM, passed to a page's internal JavaScript functions, or returned as a mocked response inside an intercepted network call.
