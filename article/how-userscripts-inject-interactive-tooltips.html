How Userscripts Inject Interactive Tooltips

Userscripts extend browser functionality by executing custom client-side JavaScript on specific web pages. To inject interactive tooltips or glossaries for complex technical terms, a userscript scans the page's HTML Document Object Model (DOM), identifies target words using regular expressions or dictionary lists, wraps those terms in styled wrapper elements, and attaches event listeners that display custom floating definition overlays dynamically.

1. Document Scanning and Text Matching

The process begins by locating specific technical terms within the web page. A userscript scans the page content using the DOM TreeWalker API or standard DOM selectors. To avoid breaking layout structures or script execution, the script targets only raw text nodes inside content containers (such as paragraphs or article bodies), explicitly ignoring <script>, <style>, and <input> tags.

Using a regular expression compiled from a list of glossary terms, the script evaluates the text content of each node to find matching words.

2. Term Wrapping and DOM Modification

Once a target technical term is detected, the userscript replaces the plain text node with HTML elements—typically <span> tags—containing custom data attributes.

  • Attribute Tagging: The wrapper element is assigned a class name (such as .glossary-term) and a custom attribute containing the definition or identifier (e.g., data-definition="...").
  • Node Replacement: The original text node is split, and the new <span> node is inserted into the DOM tree at the exact location of the matched term.

3. Injecting Custom Styles and Tooltip Containers

To render the tooltips correctly over existing web content, userscripts inject dedicated CSS into the document's <head>.

  • Global Stylesheet Injection: The script appends a <style> element containing styles for highlighted terms (such as dashed underlines or background highlights) and the floating tooltip box.
  • Shadow DOM Isolation: Advanced userscripts append a hidden container using the Shadow DOM (element.attachShadow({mode: 'open'})). This prevents the target website's existing CSS rules from overriding or breaking the appearance of the tooltip box.

4. Dynamic Positioning and Event Handling

Interactivity is controlled by attaching mouse or keyboard event listeners to the newly created wrapper elements.

  • Triggering Display: The script listens for mouseenter, mouseleave, or click events on the highlighted terms.
  • Calculating Coordinates: When triggered, the event handler uses element.getBoundingClientRect() to compute the exact coordinates of the hovered word relative to the viewport.
  • Viewport Adjustments: The script updates the tooltip's top and left position properties dynamically. It includes logic to detect screen edges, placing the tooltip above, below, or to the side of the term so it never renders off-screen.

5. On-Demand Glossary Fetching

For large technical glossaries, storing thousands of definitions in memory is inefficient. Userscripts often store only a term mapping list. When a user interacts with a term, the script uses standard fetch() calls or browser extension APIs (like GM_xmlhttpRequest) to pull the definition asynchronously from a remote API or JSON file before populating the tooltip.
