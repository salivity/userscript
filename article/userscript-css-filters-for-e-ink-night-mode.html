Userscript CSS Filters for E-Ink Night Mode

Userscripts create custom night-mode overlays for e-ink monitors by dynamically injecting JavaScript into web pages to manipulate Cascading Style Sheets (CSS) filter properties and DOM elements. Unlike standard LCD or OLED displays, e-ink monitors rely on reflective ambient light and high contrast rather than dark black backgrounds to maintain readability. By combining CSS inversion, grayscale, contrast adjustments, and non-blocking overlay elements, userscripts tailor web content to the specific optical and refresh rate requirements of e-ink hardware.

Injecting Global CSS Filters

Browsers allow userscripts (managed via extensions like Tampermonkey or Violentmonkey) to run custom styles before or after a page renders. To alter page appearance globally, a script targets the root <html> or <body> element and applies the CSS filter property. A basic inversion filter like filter: invert(100%) flips a light website background to dark, but for e-ink displays, full inversion often creates severe contrast issues or slow refresh responses. Userscripts mitigate this by applying targeted combinations:

html {
  filter: invert(90%) hue-rotate(180deg) grayscale(100%) contrast(120%);
}
  • Inversion (invert()): Flips light backgrounds to dark shades while preserving legibility.
  • Hue Rotation (hue-rotate()): Rotates color wheels back to near-original hues after inversion, preventing inverted media from appearing distorted.
  • Grayscale (grayscale(100%)): Strips color data completely, optimizing the rendering pipeline for e-ink displays that only output grayscale levels.
  • Contrast (contrast()): Increases edge sharpness between text and background, reducing visual ghosting on e-ink panels.

Reverting Embedded Media

Inverting the entire document flips images, videos, and canvas elements into negative space, making them unreadable. Userscripts resolve this by applying a secondary, counter-acting CSS filter directly to specific media tags (img, video, picture, iframe).

img, video, canvas {
  filter: invert(100%) hue-rotate(180deg);
}

This second inversion restores images to their original appearance while keeping the surrounding page background dark and low-glare.

Creating Custom Blend-Mode Overlays

Rather than relying solely on the CSS filter property on the document root, advanced userscripts inject fixed HTML overlay elements directly into the DOM. This method avoids heavy visual artifacts and reduces rendering lag on e-ink hardware.

const overlay = document.createElement('div');
overlay.style.cssText = `
  position: fixed;
  top: 0;
  left: 0;
  width: 100vw;
  height: 100vh;
  background-color: #222222;
  mix-blend-mode: difference;
  pointer-events: none;
  z-index: 999999;
`;
document.documentElement.appendChild(overlay);

The mix-blend-mode: difference property mathematically subtracts element colors from the overlay color, effectively creating a dark mode. Setting pointer-events: none ensures the overlay remains invisible to user inputs like clicking or scrolling.

Optimizing CSS for E-Ink Hardware

E-ink displays suffer from slow pixel response times and full-screen flashing during rapid layout changes. Userscripts incorporate hardware-specific optimizations to prevent performance degradation:

  1. Disabling Transitions and Animations: CSS smooth scrolling and color transitions cause e-ink screens to flash repeatedly as intermediate frames render. Userscripts inject global rules (* { transition: none !important; animation: none !important; }) to force instant frame updates.
  2. Off-Black Backgrounds: Pure black (#000000) on e-ink panels causes heavy ghosting when transitioning back to white text or light elements. Scripts manipulate filters to target dark grays (#1e1e1e or #2d2d2d), which clear much faster on e-ink hardware.
  3. Sharpening Text Rendering: Userscripts adjust -webkit-font-smoothing and text-shadow properties alongside CSS contrast filters to maintain crisp text outlines, compensating for the lack of subpixel rendering on grayscale panels.
