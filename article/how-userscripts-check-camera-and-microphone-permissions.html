How Userscripts Check Camera and Microphone Permissions

Userscripts leverage the browser's native Permissions API through the navigator.permissions object to inspect whether a website has been granted access to the camera or microphone. By calling the query() method with the appropriate media descriptor, userscripts can determine if access is granted, denied, or requires a user prompt, allowing them to adjust custom functionality without unnecessarily re-triggering browser permission popups.

Using navigator.permissions.query()

Because userscripts execute within the web page's context, they inherit access to standard Web APIs. To check the status of media devices, a userscript invokes navigator.permissions.query() by passing a permission descriptor object specifying either 'camera' or 'microphone'.

async function checkMediaPermissions() {
  try {
    const cameraStatus = await navigator.permissions.query({ name: 'camera' });
    const micStatus = await navigator.permissions.query({ name: 'microphone' });

    console.log(`Camera status: ${cameraStatus.state}`);
    console.log(`Microphone status: ${micStatus.state}`);

    return {
      camera: cameraStatus.state,
      microphone: micStatus.state
    };
  } catch (error) {
    console.error('Permissions API error or descriptor not supported:', error);
  }
}

Interpreting Permission States

The PermissionStatus object returned by query() contains a state property with one of three string values:

  • granted: Access has already been given. The script can call navigator.mediaDevices.getUserMedia() to stream media without prompting the user.
  • prompt: Permission has not been decided yet. Attempting to use the device will display the browser's native permission dialog.
  • denied: Access is explicitly blocked. Calling getUserMedia() will automatically throw a NotAllowedError.

Listening for Real-Time Permission Changes

Userscripts can monitor changes to media permissions dynamically using the onchange event listener on the PermissionStatus object. This allows the script to react immediately if the user grants or revokes permissions via browser settings while staying on the page.

async function monitorCameraPermission() {
  const cameraStatus = await navigator.permissions.query({ name: 'camera' });

  cameraStatus.onchange = () => {
    console.log(`Camera access state updated to: ${cameraStatus.state}`);
    if (cameraStatus.state === 'granted') {
      // Enable camera features in the userscript
    } else if (cameraStatus.state === 'denied') {
      // Disable camera features in the userscript
    }
  };
}

Environment Considerations for Userscripts

  • Secure Context (HTTPS): The Permissions API and media devices require a secure context. Userscripts operating on http:// sites will find navigator.permissions restricted or undefined for media queries.
  • Origin Rules: Permissions are tied directly to the host domain (the web page where the userscript runs), not the userscript manager extension.
  • Browser Compatibility: Chromium-based browsers fully support the { name: 'camera' } and { name: 'microphone' } query descriptors. In environments where these descriptors are not supported, userscripts usually fall back to calling navigator.mediaDevices.enumerateDevices() to check if hardware labels are visible, which indirectly indicates if access was granted.
