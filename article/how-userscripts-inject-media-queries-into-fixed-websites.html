How Userscripts Inject Media Queries into Fixed Websites

Userscripts transform rigid, fixed-width websites into mobile-friendly, responsive layouts by programmatically overriding existing CSS, modifying metadata, and injecting dynamic custom stylesheets directly into the browser's Document Object Model (DOM). By utilizing browser extensions like Tampermonkey or Violentmonkey, these scripts insert custom @media queries and manipulate viewport settings after the page loads. This article explains the exact technical process userscripts use to force fixed-width websites to adapt seamlessly to modern screen sizes.

1. Injecting or Modifying the Viewport Meta Tag

Fixed-width websites often lack a responsive viewport meta tag, causing mobile browsers to render the page at a scaled-down desktop width. Userscripts fix this fundamental issue by checking the document head and programmatically adding or updating the viewport tag before applying media queries.

let meta = document.querySelector('meta[name="viewport"]');
if (!meta) {
    meta = document.createElement('meta');
    meta.name = 'viewport';
    document.head.appendChild(meta);
}
meta.content = 'width=device-width, initial-scale=1.0';

Without this tag, media queries based on screen width (max-width) will fail to trigger correctly on mobile devices.

2. Overriding Existing Rigid CSS Rules

Fixed-width sites rely on hardcoded pixel values (e.g., width: 1200px;). Userscripts bypass these restrictions by constructing CSS rules that use fluid units (like %, vw, or max-width) combined with the !important declaration to override existing stylesheet specifications.

Key targets for overrides include:

  • Converting fixed width properties to max-width: 100%.
  • Setting container elements to width: auto.
  • Changing absolute positioning or float layouts to flexible box (display: flex) or CSS Grid layouts.

3. Injecting the CSS with Custom @media Queries

Userscripts inject these new rules into the webpage through direct DOM manipulation or script manager helper functions like GM_addStyle.

Method A: Native DOM Injection

const style = document.createElement('style');
style.textContent = `
    @media screen and (max-width: 768px) {
        #main-container, .wrapper, #header {
            width: 100% !important;
            min-width: 0 !important;
            box-sizing: border-box !important;
        }
        .sidebar {
            float: none !important;
            width: 100% !important;
        }
    }
`;
document.head.appendChild(style);

Method B: Using GM_addStyle

Script managers provide GM_addStyle, which injects styles instantly without manually creating HTML nodes:

GM_addStyle(`
    @media (max-width: 600px) {
        body { padding: 10px !important; }
        table { display: block !important; overflow-x: auto !important; }
    }
`);

4. Stripping Inline Style Attributes

Some older websites define fixed widths directly on HTML elements using inline styles (e.g., <div style="width: 960px;">). CSS media queries alone may struggle to override inline styles without high specificity. Userscripts run JavaScript loops to strip or modify these attributes dynamically:

document.querySelectorAll('[style]').forEach(el => {
    if (el.style.width) {
        el.style.maxWidth = '100%';
        el.style.width = 'auto';
    }
});

5. Handling Dynamic Content with Observers and matchMedia

For modern single-page applications or sites that render elements lazily, userscripts monitor layout changes using MutationObserver or execution triggers based on screen resizing with window.matchMedia().

const mediaQuery = window.matchMedia('(max-width: 768px)');

function handleMobileLayout(e) {
    if (e.matches) {
        // Run JavaScript logic specific to mobile screens
        document.body.classList.add('mobile-view');
    } else {
        document.body.classList.remove('mobile-view');
    }
}

mediaQuery.addEventListener('change', handleMobileLayout);
handleMobileLayout(mediaQuery);

By combining viewport normalization, CSS override injection, inline attribute removal, and JavaScript event listeners, userscripts effectively rebuild the layout pipeline of legacy fixed-width websites to render responsively across all devices.
