How to Use GM_addStyle in Userscripts

The GM_addStyle function is a built-in helper provided by popular userscript managers like Tampermonkey and Greasemonkey that allows developers to inject custom CSS directly into a webpage. By simplifying the process of dynamic style injection, it enables users to seamlessly alter the appearance, layout, or responsiveness of any site. This article explains what GM_addStyle is, how to enable it in your userscript headers, and provides clear examples of how to apply custom CSS rules efficiently.

What is GM_addStyle?

When modifying a web page's design via standard JavaScript, developers typically have to create a <style> element, insert CSS text into it, and append it to the document's <head> element.

The GM_addStyle function abstracts this standard DOM manipulation. It accepts a string of raw CSS, creates the necessary HTML style node, attaches your custom styles, and appends the node to the active document automatically.

Enabling GM_addStyle in Your Script

To use GM_addStyle, you must explicitly request access to it in the userscript metadata block using the @grant directive.

// ==UserScript==
// @name         Custom Style Injector
// @namespace    http://tampermonkey.net/
// @version      1.0
// @match        https://example.com/*
// @grant        GM_addStyle
// ==UserScript==

If you do not include // @grant GM_addStyle, the manager will restrict access to the function, causing your script to throw a ReferenceError.

How to Apply GM_addStyle

Once granted, you invoke GM_addStyle by passing a string containing valid CSS rules as its argument.

Single-Line Injection

For small modifications, pass a short CSS string directly:

GM_addStyle('body { background-color: #f0f0f0 !important; }');

Multi-Line Injection

For extensive visual redesigns, JavaScript template literals (backticks) allow you to write formatted, multi-line CSS rules cleanly:

GM_addStyle(`
    .sidebar, .ad-container {
        display: none !important;
    }
    .main-content {
        width: 100% !important;
        max-width: 1200px;
        margin: 0 auto;
    }
    a {
        color: #0066cc;
        text-decoration: underline;
    }
`);

Best Practices

  • Override Existing Styles: Web pages often use high-specificity CSS selectors. Append !important to your custom CSS declarations to guarantee they override the site's default styles.
  • Document Injection Timing: GM_addStyle handles DOM readiness automatically. Even if your script executes before the page finishes loading (@run-at document-start), the manager will safely attach the styles as soon as the DOM is capable of receiving them.
