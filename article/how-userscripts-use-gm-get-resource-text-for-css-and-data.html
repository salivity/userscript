How Userscripts Use GM_getResourceText for CSS and Data

Userscripts often rely on external assets such as custom CSS stylesheets, template files, or raw text data to modify web pages. The GM_getResourceText function, available in userscript managers like Tampermonkey and Violentmonkey, enables scripts to access the raw text of these pre-downloaded external files. By defining external files in the script's metadata header, developers can fetch, cache, and utilize external code or assets securely and efficiently without facing cross-origin restrictions.

Step 1: Declaring Resources in the Metadata Block

Before GM_getResourceText can access an external file, the resource must be declared in the userscript's metadata block using the @resource directive. You must also grant the script permission to use the GM_getResourceText API with the @grant directive.

// ==UserScript==
// @name         External Resource Loader Example
// @namespace    http://tampermonkey.net/
// @version      1.0
// @description  Demonstrate GM_getResourceText
// @match        https://example.com/*
// @resource     customCSS https://example.com/styles.css
// @resource     configData https://example.com/data.json
// @grant        GM_getResourceText
// @grant        GM_addStyle
// ==UserScript==

In this block:

  • @resource customCSS ... assigns the identifier customCSS to the stylesheet URL.
  • @resource configData ... assigns the identifier configData to the JSON data URL.
  • @grant GM_getResourceText requests permission to call the function.

The userscript manager downloads and caches these resources when the script is installed or updated.

Step 2: Retrieving Resource Content

To retrieve the text content of a declared resource, pass the resource name as a string parameter to GM_getResourceText.

const cssText = GM_getResourceText("customCSS");
const jsonText = GM_getResourceText("configData");

If the resource exists and was successfully downloaded, the function returns a string containing the raw text of the file.

Step 3: Injecting External CSS into the Page

Once the CSS string is retrieved, it can be applied to the target website. The most common method is combining GM_getResourceText with GM_addStyle or creating a standard HTML <style> element.

Using GM_addStyle:

const myCss = GM_getResourceText("customCSS");
GM_addStyle(myCss);

Using Vanilla JavaScript:

const myCss = GM_getResourceText("customCSS");
const styleElement = document.createElement("style");
styleElement.textContent = myCss;
document.head.appendChild(styleElement);

Step 4: Parsing External Data

If the loaded resource is formatted data, such as JSON, it must be parsed after retrieval.

const rawJson = GM_getResourceText("configData");

try {
    const data = JSON.parse(rawJson);
    console.log("Loaded data:", data);
} catch (error) {
    console.error("Failed to parse JSON resource:", error);
}

Advantages of Using GM_getResourceText

  • Bypasses CORS Restrictions: Because the browser extension downloads the resource outside the webpage context, Cross-Origin Resource Sharing (CORS) rules do not block the request.
  • Offline Availability and Speed: Resources are saved locally in the userscript manager storage, ensuring instant loading without making additional network requests on every page load.
  • Security: The source URL is defined inside the script metadata, preventing dynamic injection of untrusted third-party script URLs at runtime.
