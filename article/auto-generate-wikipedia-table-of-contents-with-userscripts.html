Auto-Generate Wikipedia Table of Contents with Userscripts

Userscripts can easily auto-generate and insert custom table-of-contents (TOC) menus into long Wikipedia articles to enhance navigation. By running lightweight JavaScript through browser extensions like Tampermonkey or Violentmonkey, these scripts scan an article's heading tags, construct a dynamic outline, and inject a fixed, floating, or enhanced TOC menu directly onto the page.

How Userscripts Generate a Table of Contents

Userscripts interact directly with the Document Object Model (DOM) of a Wikipedia page after it loads. The process works in three basic steps:

  1. Scanning Headings: The script queries the page HTML for structural heading elements (such as <h2>, <h3>, and <h4> tags).
  2. Building the Menu: It extracts the text titles and corresponding element IDs from these headings to create a hierarchical nested list.
  3. Injecting the DOM Element: The script creates a styled HTML container for the new menu—such as a persistent sidebar or floating modal—and attaches it to the page layout.

Key Advantages of Custom TOC Scripts

While Wikipedia includes a built-in table of contents, custom userscripts provide significant usability improvements for long, dense entries:

  • Persistent Scrolling Visibility: Floating or sticky TOC menus remain pinned to the screen while scrolling, eliminating the need to return to the top of the article to jump between sections.
  • Active Section Tracking (Scroll-Spy): Scripts can automatically highlight the heading currently visible in the viewport, making it easier to maintain context within massive articles.
  • Collapsible Levels: Users can expand or collapse sub-sections dynamically to keep the outline clean and readable.
  • In-Menu Filtering: Some advanced scripts add a micro-search bar inside the generated TOC, allowing instant filtering of sections by keyword.

Setting Up a TOC Userscript

Setting up an automated TOC on Wikipedia requires two components:

  1. A Userscript Manager: Install a browser extension such as Tampermonkey, Violentmonkey, or Greasemonkey.
  2. The Script: Download an existing Wikipedia TOC script from repositories like Greasy Fork, or write a custom script set to execute on https://*.wikipedia.org/wiki/*.

Once active, the script runs automatically in the background whenever a Wikipedia article loads, instantly parsing the page and displaying the enhanced navigation menu.
