How to Use matchMedia for Dark Mode in Userscripts

Userscripts can automatically adjust their styling or script behavior based on a user's system theme preferences using the browser's native window.matchMedia API. This article explains how userscripts query the prefers-color-scheme media feature, listen for live OS or browser theme toggles, and dynamically inject styles or execute code to seamlessly support dark mode.

Checking the User's Dark Mode Preference

The window.matchMedia method accepts a CSS media query string and returns a MediaQueryList object. To check if the operating system or browser is currently set to dark mode, evaluate the prefers-color-scheme: dark media feature.

const darkModeQuery = window.matchMedia('(prefers-color-scheme: dark)');

if (darkModeQuery.matches) {
    console.log('Dark mode is currently active.');
} else {
    console.log('Light mode is currently active.');
}

The .matches boolean property immediately indicates whether the user prefers a dark interface at the moment the script runs.

Listening for Real-Time Theme Changes

Users may switch their system theme between light and dark modes while a web page is open. Userscripts can respond immediately without requiring a page reload by attaching an event listener to the MediaQueryList object.

darkModeQuery.addEventListener('change', (event) => {
    if (event.matches) {
        applyDarkMode();
    } else {
        applyLightMode();
    }
});

Using addEventListener('change', callback) ensures the userscript automatically updates UI elements, custom stylesheets, or script configurations whenever the system color scheme changes.

Injecting Dynamic Styles in Userscripts

To modify the visual presentation, userscripts typically inject custom CSS or toggle classes on the document element (document.documentElement or document.body).

Example Implementation

Here is a complete, minimal implementation demonstrating detection, dynamic style injection, and event handling within a userscript environment:

// ==UserScript==
// @name         Dark Mode Detector
// @match        https://*/*
// @run-at       document-start
// ==/UserScript==

(function() {
    'use strict';

    const darkModeQuery = window.matchMedia('(prefers-color-scheme: dark)');

    function updateTheme(isDark) {
        if (isDark) {
            document.documentElement.classList.add('custom-dark-mode');
        } else {
            document.documentElement.classList.remove('custom-dark-mode');
        }
    }

    // Initial check on load
    updateTheme(darkModeQuery.matches);

    // Listen for live theme updates
    darkModeQuery.addEventListener('change', (e) => updateTheme(e.matches));
})();

By leveraging matchMedia alongside DOM element class toggling or Userscript style injection APIs (like GM_addStyle), scripts maintain consistent visual harmony with the user's preferred operating system theme.
