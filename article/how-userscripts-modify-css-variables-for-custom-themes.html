How Userscripts Modify CSS Variables for Custom Themes

Userscripts alter website themes globally by targeting CSS variables (custom properties) defined on the document's root element. By using browser extension managers like Tampermonkey or Violentmonkey, these scripts inject custom CSS rules or directly manipulate JavaScript DOM properties before or during page render. This approach allows users to change color schemes, fonts, and layouts across entire websites without rewriting complex stylesheet rules.

Understanding CSS Variables and the Root Element

Modern websites often define key design tokens—such as background colors, text colors, and spacing—within the :root pseudo-class of their stylesheets. A typical website stylesheet might look like this:

:root {
  --main-bg-color: #ffffff;
  --main-text-color: #1a1a1a;
  --accent-color: #0066cc;
}

Because elements across the site reference these specific variables, modifying the variables at the root level updates the entire site's theme automatically.

Method 1: Injecting CSS Overrides

The most popular approach for userscripts is injecting a custom <style> element into the webpage document. By redeclaring the :root variables and using the !important flag, the script ensures its values take priority over the native site styles.

// ==UserScript==
// @name         Global Theme Modifier
// @namespace    http://tampermonkey.net/
// @version      1.0
// @match        https://example.com/*
// @run-at       document-start
// @grant        GM_addStyle
// ==UserScript==

const customCSS = `
  :root {
    --main-bg-color: #121212 !important;
    --main-text-color: #e0e0e0 !important;
    --accent-color: #bb86fc !important;
  }
`;

// Using GM_addStyle helper if supported, or creating a style tag
if (typeof GM_addStyle !== 'undefined') {
  GM_addStyle(customCSS);
} else {
  const style = document.createElement('style');
  style.textContent = customCSS;
  (document.head || document.documentElement).appendChild(style);
}

Method 2: Direct Inline DOM Manipulation

Userscripts can also interact directly with the DOM using JavaScript's setProperty method on document.documentElement.style. Inline styles set on the root element automatically override declarations in external stylesheets.

// Function to update individual custom properties directly
function setGlobalCSSVariable(name, value) {
  document.documentElement.style.setProperty(name, value);
}

// Example usage to set dark mode properties
setGlobalCSSVariable('--main-bg-color', '#121212');
setGlobalCSSVariable('--main-text-color', '#ffffff');

This dynamic approach is useful when creating userscripts that include settings panels, color pickers, or automatic day/night mode toggles, as values can be changed instantly in response to user events.

Preventing Flash of Unstyled Content (FOUC)

A common challenge when modifying site themes is preventing the original theme from briefly loading before the script runs. Userscripts prevent this by using the @run-at document-start directive in their metadata block.

Executing at document-start injects the style overrides into document.documentElement before the browser parses the <body> or renders the page content, ensuring a seamless visual change across all pages on the site.
