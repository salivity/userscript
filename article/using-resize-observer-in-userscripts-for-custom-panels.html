Using ResizeObserver in Userscripts for Custom Panels

Userscripts frequently inject custom UI panels into third-party websites, but keeping these panels aligned and sized correctly as the browser layout changes can be challenging. By leveraging the JavaScript ResizeObserver API, userscripts can monitor real-time dimension changes of specific DOM elements—such as responsive sidebars or main content containers—and automatically recalculate and adjust custom panel dimensions without relying on laggy window resize events or performance-heavy polling loops.

Why Userscripts Need ResizeObserver

Traditional web development often relies on the window.onresize event listener to handle layout updates. However, window resize events only fire when the entire browser window changes dimensions, missing key layout changes like collapsed sidebars, toggled navigation menus, or dynamic content loading within Single Page Applications (SPAs).

ResizeObserver solves this by directly monitoring specific DOM nodes. For userscripts, this means custom floating, docked, or injected panels can react to localized changes in their parent containers instantly.

How the Implementation Works

Integrating ResizeObserver into a userscript involves four primary steps:

  1. Target Identification: The script identifies the existing web page element that determines the available space (e.g., #main-content or .sidebar-container).
  2. Observer Instantiation: A new ResizeObserver instance is created, initialized with a callback function that handles the resizing logic.
  3. Panel Adjustment Logic: Inside the callback, the script reads the target's updated contentRect properties (width, height, top, left) and applies updated inline styles to the custom panel.
  4. Observation Initialization: The script attaches the targeted element to the observer using the .observe() method.

Practical JavaScript Code Pattern

Below is a standard pattern used within Tampermonkey or Violentmonkey userscripts to keep an injected panel synchronized with a site's main content wrapper:

// 1. Create and inject the custom panel
const customPanel = document.createElement('div');
customPanel.id = 'my-custom-panel';
customPanel.style.position = 'absolute';
customPanel.style.backgroundColor = '#f0f0f0';
customPanel.style.transition = 'width 0.1s, height 0.1s';
document.body.appendChild(customPanel);

// 2. Identify the element to track
const targetContainer = document.querySelector('#main-content');

// 3. Define the ResizeObserver callback
const resizeObserver = new ResizeObserver(entries => {
  for (let entry of entries) {
    // Extract new dimensions of the target container
    const { width, left, top } = entry.contentRect;

    // Adjust the custom panel to match or offset based on container size
    customPanel.style.width = `${width * 0.25}px`; // Occupy 25% of container width
    customPanel.style.left = `${left + width + 10}px`; // Position next to container
    customPanel.style.top = `${top}px`;
  }
});

// 4. Start observing the container
if (targetContainer) {
  resizeObserver.observe(targetContainer);
}

Advantages of Using ResizeObserver in Userscripts

  • Performance Optimization: Unlike standard resize listeners that fire constantly during drag operations, ResizeObserver is optimized by the browser rendering engine to prevent layout thrashing and unnecessary recalculations.
  • Element-Level Precision: The script responds to size changes of individual wrapper elements, ensuring the custom UI scales correctly even if the browser window size remains identical.
  • Clean Cleanup: When dynamic SPAs destroy or replace DOM nodes, calling resizeObserver.disconnect() prevents memory leaks in long-running browser sessions.
