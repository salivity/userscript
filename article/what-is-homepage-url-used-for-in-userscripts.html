What Is @homepageURL Used for in Userscripts?

The @homepageURL directive is a metadata tag used in userscript development to specify the official web page or source repository of a script. When included in the ==UserScript== header block, it tells userscript managers like Tampermonkey, Violentmonkey, and Greasemonkey where the script is hosted or documented. This provides users with a direct link to the script's home page, facilitates user support, and helps managers link back to the primary source code location.

Primary Uses of @homepageURL

1. Dashboard Navigation

Userscript managers present installed scripts in a dashboard interface. When you define @homepageURL, the manager turns the script name or a dedicated home button into a clickable link. This allows users to quickly navigate to the script's web page directly from their browser extension settings.

2. Source Code and Repository Linking

Developers frequently set @homepageURL to point to a public repository host, such as GitHub or GitLab. This makes it easy for other developers and tech-savvy users to inspect the full codebase, review commit histories, or fork the project.

3. Centralized Documentation and Support

Rather than embedding long tutorials or change logs directly inside the code, developers use @homepageURL to send users to external documentation, installation guides, or release notes.

Syntax and Example

To use the directive, add @homepageURL followed by the full web address inside the script's metadata block at the top of the file:

// ==UserScript==
// @name         My Website Customizer
// @namespace    http://example.com/
// @version      1.0.0
// @description  Modifies the layout of targeted websites.
// @author       John Doe
// @homepageURL  https://github.com/johndoe/my-website-customizer
// @match        https://*.example.com/*
// @grant        none
// ==UserScript==

Related Metadata Directives

  • @homepage: Functionally identical to @homepageURL in most modern userscript managers and serves as a direct alias.
  • @supportURL: Points specifically to a page where users can submit bug reports or support requests (e.g., a GitHub Issues page).
  • @updateURL: Points to the raw script file used by the extension to check for code updates, distinct from the human-readable homepage.
