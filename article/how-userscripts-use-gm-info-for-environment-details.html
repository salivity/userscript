How Userscripts Use GM_info for Environment Details

Userscripts leverage the GM_info object as a built-in read-only API to extract crucial metadata about the running script and its execution context. Provided automatically by userscript managers like Tampermonkey, Violentmonkey, and Greasemonkey, GM_info allows developers to inspect script settings, identify the browser extension running the script, and handle environment-specific logic dynamically without hardcoding metadata.

Key Properties of the GM_info Object

The GM_info object contains several structured properties that store details parsed directly from the script's ==UserScript== header block, alongside environment configuration details.

  • GM_info.script: Contains all parsed metadata defined in the header, such as name, version, namespace, description, matches, includes, and declared @grant directives.
  • GM_info.scriptHandler: Returns a string identifying the active userscript manager (for example, "Tampermonkey", "Violentmonkey", or "Greasemonkey").
  • GM_info.version: Specifies the version number of the userscript manager extension executing the script.
  • GM_info.scriptWillUpdate: A boolean flag indicating whether the manager expects the script to automatically update.
  • GM_info.injectInto: Indicates the injection mode used by managers that support custom context contexts (such as "page", "content", or "auto").

Reading Script Metadata

Developers frequently use GM_info.script to retrieve information about the current script instance. This is useful for debugging, dynamically generating UI elements, or sending telemetry data with accurate version headers.

const scriptName = GM_info.script.name;
const scriptVersion = GM_info.script.version;

console.log(`Running ${scriptName} v${scriptVersion}`);

Detecting the Userscript Engine

Because different script managers support slightly different API features or execution behaviors, GM_info.scriptHandler provides a reliable way to apply target-specific patches or feature detection based on the user's environment.

const handler = GM_info.scriptHandler;
const handlerVersion = GM_info.version;

if (handler === "Tampermonkey") {
    console.log(`Running on Tampermonkey version ${handlerVersion}`);
} else if (handler === "Violentmonkey") {
    console.log(`Running on Violentmonkey version ${handlerVersion}`);
}

Practical Applications

  • Debugging and Analytics: Automatically include the script version, engine type, and browser details in console output or error logging wrappers.
  • Compatibility Branching: Apply fallback behavior if a specific script manager or minimum engine version is detected.
  • Dynamic Settings Panels: Build user interfaces within the page that display metadata, such as current version or namespace, pulled straight from the script headers.
