How Userscripts Inject AI Translation Bubbles

Userscripts create floating AI-powered translation bubbles by detecting user text selections, sending that text to an artificial intelligence API, calculating the exact screen coordinates of the selected text, and injecting a custom, isolated HTML element onto the webpage. Through browser extension managers like Tampermonkey or Violentmonkey, these scripts bridge the gap between webpage DOM manipulation, background API calls, and dynamic CSS positioning to display real-time translations seamlessly over foreign text.

1. Text Detection and Selection Capture

The script listens for user interactions on the webpage using JavaScript event listeners such as mouseup, keyup, or selectionchange. When a user highlights foreign text, the script uses the browser's native window.getSelection() API to retrieve the highlighted string along with its specific node location in the Document Object Model (DOM).

2. Dynamic Position Calculation

To place the translation bubble directly above or beside the highlighted text, the userscript calculates precise coordinates using the Range.getBoundingClientRect() method. This returns the text selection's width, height, and position relative to the viewport:

  • X-Coordinate: Positioned horizontally aligned with the start or center of the selection.
  • Y-Coordinate: Positioned vertically just above the top edge (or below the bottom edge) of the selected text block, accounting for page scroll offsets (window.scrollY).

3. Asynchronous AI API Requests

Once text is captured, the userscript sends a payload containing the foreign text and instructions (such as target language and contextual prompt) to an external AI API, such as OpenAI, DeepL, or Anthropic.

Because standard web requests might be blocked by Cross-Origin Resource Sharing (CORS) policies on host websites, userscripts utilize privileged APIs like GM_xmlhttpRequest or standard fetch() requests configured with background script permissions to safely communicate with external servers.

4. DOM Injection and UI Isolation

While waiting for or receiving the translation stream, the script dynamically creates a floating UI container (usually a <div>) and appends it to the document body.

To prevent the target website's existing CSS from messing up the bubble's styling, advanced userscripts attach a Shadow DOM root (element.attachShadow({mode: 'open'})). This creates a encapsulated sub-DOM tree, guaranteeing that the translation bubble's buttons, loading spinners, and typography render consistently regardless of the host site's stylesheet.

5. Overlay Styling and Cleanup

The floating element is styled using absolute or fixed CSS positioning:

  • position: absolute (or fixed) ensures it floats over underlying text without breaking the page layout.
  • z-index: 999999 guarantees the bubble appears above all other web elements.
  • pointer-events: auto allows users to click, copy, or close the translation.

Finally, the script adds global click listeners to remove or hide the bubble whenever the user clicks elsewhere on the page or clears the text selection.
