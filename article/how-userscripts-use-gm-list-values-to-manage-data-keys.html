How Userscripts Use GM_listValues to Manage Data Keys

GM_listValues is a specialized function provided by userscript managers like Tampermonkey, Violentmonkey, and Greasemonkey that allows developers to retrieve an array of all key names currently stored in a script's persistent storage. By returning a complete list of stored keys, GM_listValues enables scripts to dynamically inspect, iterate over, export, or clean up stored data without needing to hardcode key names. This makes it an essential tool for managing dynamic data, implementing settings managers, and preventing storage bloat in web automation and custom browser enhancements.

Understanding the Functionality of GM_listValues

When a userscript saves data using GM_setValue, the data is stored as a key-value pair unique to that specific script. GM_listValues acts as an inventory tool for this storage space. Calling the function scans the script's dedicated storage environment and returns an array of strings representing every existing key.

Basic Syntax

Depending on the API version used by your script manager, GM_listValues is called in one of two ways:

  • Synchronous (Greasemonkey 3 / Tampermonkey standard): 
    // @grant GM_listValues
const keys = GM_listValues();
  • Asynchronous (Greasemonkey 4+ GM. API):* 
    // @grant GM.listValues
const keys = await GM.listValues();

Key Use Cases in Userscript Development

1. Iterating Over Stored Data

When keys are generated dynamically—such as saving user settings per domain or storing unique item IDs—developers cannot rely on hardcoded key names. By using GM_listValues, a script can loop through all keys to retrieve their corresponding values using GM_getValue.

const allKeys = GM_listValues();

allKeys.forEach(key => {
    const value = GM_getValue(key);
    console.log(`Key: ${key}, Value: ${value}`);
});

2. Bulk Data Deletion and Storage Cleanup

GM_deleteValue requires a specific key name to remove an entry. If a script needs to clear temporary cache items or perform a full factory reset, GM_listValues can be paired with GM_deleteValue to clear storage programmatically.

// Remove all stored keys matching a specific prefix
const keys = GM_listValues();

keys.forEach(key => {
    if (key.startsWith('cache_')) {
        GM_deleteValue(key);
    }
});

3. Importing and Exporting User Data

Userscripts that offer configuration panels often allow users to back up or restore their settings. GM_listValues makes it simple to construct a complete JSON object containing all stored keys and values for export, or to inspect existing keys before importing new data.

function exportData() {
    const keys = GM_listValues();
    const backup = {};

    keys.forEach(key => {
        backup[key] = GM_getValue(key);
    });

    return JSON.stringify(backup);
}

Best Practices

  • Declare Grants Correctly: Always include // @grant GM_listValues (or // @grant GM.listValues) in the userscript metadata block. Without this declaration, the function will be undefined.
  • Handle Async vs. Sync APIs: Check which API standard your target script manager supports. Modern cross-browser scripts targeting Greasemonkey 4 standard should handle promises when calling GM.listValues().
  • Avoid Key Collisions: Since GM_listValues returns all keys for the script, use consistent naming conventions (like prefixes) when storing different types of data (e.g., setting_theme, cache_page1). This allows easy filtering when retrieving specific subsets of stored data.
