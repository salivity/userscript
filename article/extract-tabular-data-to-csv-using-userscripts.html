Extract Tabular Data to CSV Using Userscripts

Userscripts automate the extraction of web-based tabular data by injecting custom JavaScript into a browser page to target specific elements, parse row and cell contents, format the plain text into a Comma-Separated Values (CSV) structure, and automatically trigger a file download compatible with Microsoft Excel.

1. Locating and Accessing Tabular Data

Userscripts use Document Object Model (DOM) queries to target tables on a webpage.

  • Standard HTML tables are selected using methods like document.querySelectorAll('table') or specific class/ID selectors.
  • Dynamic or non-standard tables (such as <div>-based grids) are targeted by selecting repeating parent and child structural elements.

2. Extracting and Cleaning Cell Values

Once targeted, the script iterates through each row (<tr>) and individual cell (<td> or <th>).

  • Text Extraction: The script reads the raw text content using properties like innerText or textContent.
  • Data Sanitization: Line breaks, extra spaces, and HTML tags are stripped out to clean up the data.
  • CSV Escaping: If a cell contains a comma, double quote, or newline character, the script wraps the text in double quotes ("...") and doubles any existing quote marks ("") to prevent breaking the CSV structure.

3. Formatting Data as CSV

The script builds a structured text string line by line:

  • Cell contents within the same row are joined using commas (or semicolons for standard European regional settings).
  • Rows are joined using newline characters (\n or \r\n).
  • A Byte Order Mark (BOM) code (\uFEFF) is often added to the beginning of the string to force Excel to correctly interpret UTF-8 encoded characters.

4. Triggering the File Download

To send the CSV file directly to the user's computer without server interaction, the script uses browser APIs:

  1. Blob Creation: Converts the formatted CSV string into a binary Blob object with the MIME type text/csv;charset=utf-8;.
  2. URL Generation: Uses URL.createObjectURL(blob) to create a temporary download link in the browser memory.
  3. Automated Click: Programmatically creates a hidden <a> element, sets the href attribute to the blob URL, assigns a .csv file name to the download attribute, attaches it to the DOM, clicks it, and immediately removes it.

Excel automatically detects the downloaded .csv file and arranges the comma-delimited data directly into columns and rows upon opening.
