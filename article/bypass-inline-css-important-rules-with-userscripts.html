Bypass Inline CSS Important Rules with Userscripts

Inline CSS styles defined with the !important declaration occupy the highest priority level in the standard CSS cascade, preventing normal external stylesheets from overriding them. Userscripts bypass this restriction by using JavaScript to interact directly with the Document Object Model (DOM). Instead of relying on CSS specificity, userscripts modify element style properties at runtime, strip inline attributes entirely, or observe DOM changes to suppress dynamically enforced styles.

The Challenge of Inline !important Styles

In the CSS cascade, specificity determines which rule applies to an element. An inline style (defined directly on the HTML tag via the style attribute) combined with !important overrides virtually all standard CSS declarations in author stylesheets:

<!-- Hard to override with standard CSS -->
<div id="target" style="display: block !important;">Content</div>

Because external CSS rules cannot beat an inline !important declaration, JavaScript execution via userscripts (such as Violentmonkey, Tampermonkey, or Greasemonkey) is required to break the cascade.

Method 1: Modifying Style Properties via setProperty()

JavaScript's CSSStyleDeclaration.setProperty() method allows developers to pass an optional third argument specifying priority. Setting a new value with 'important' directly overwrites the existing inline declaration.

const element = document.querySelector('#target');
if (element) {
    element.style.setProperty('display', 'none', 'important');
}

This updates the element's inline style attribute directly, replacing the old !important value with the new one.

Method 2: Removing the Inline Style Attribute

If the goal is to disable the inline styling completely so that custom CSS stylesheets can take control, the userscript can remove the style property or clear the attribute entirely.

Option A: Remove Specific Property

const element = document.querySelector('#target');
element.style.removeProperty('display');

Option B: Wipe the Entire Style Attribute

const element = document.querySelector('#target');
element.removeAttribute('style');

Once removed, standard stylesheet declarations or injected @grant GM_addStyle rules apply normally.

Method 3: Neutralizing Dynamic Inline Styles with MutationObserver

Many modern websites use JavaScript single-page applications (SPAs) or framework event handlers that continuously re-apply inline !important styles whenever a user interacts with the page. To counter this, userscripts use a MutationObserver to watch for attribute modifications and instantly override them.

const targetNode = document.querySelector('#target');

const observer = new MutationObserver((mutationsList) => {
    for (const mutation of mutationsList) {
        if (mutation.type === 'attributes' && mutation.attributeName === 'style') {
            // Disconnect temporarily to avoid infinite loops during modification
            observer.disconnect();
            
            // Enforce desired style
            targetNode.style.setProperty('display', 'none', 'important');
            
            // Reconnect the observer
            observe();
        }
    }
});

function observe() {
    observer.observe(targetNode, { attributes: true, attributeFilter: ['style'] });
}

observe();

Method 4: Overriding Global CSS Rules via Shadow DOM

When target elements are isolated within a Web Component's Shadow DOM, userscripts access the shadowRoot to modify inline styles directly within that shadow tree.

const hostElement = document.querySelector('custom-component');
if (hostElement && hostElement.shadowRoot) {
    const internalElement = hostElement.shadowRoot.querySelector('.inner-element');
    internalElement.style.setProperty('color', 'blue', 'important');
}

Summary of Techniques

  1. setProperty('prop', 'value', 'important'): Replaces the inline rule directly.
  2. removeAttribute('style'): Completely strips inline declarations to yield control to external CSS.
  3. MutationObserver: Prevents web applications from re-enforcing inline styles dynamically.
