How to Connect Userscripts to Local LLMs

Userscripts can seamlessly integrate with local Large Language Models (LLMs) like Ollama and LM Studio by taking advantage of the local REST API endpoints exposed by these software engines. By making asynchronous HTTP requests directly from browser extensions like Tampermonkey, userscripts bypass external cloud dependencies, enabling private, automated AI features—such as text summarization, form auto-filling, and page analysis—directly within any web page.

Understanding the Local LLM Architecture

Local LLM runtimes host AI models directly on your machine and expose lightweight HTTP servers.

  • Ollama typically serves its API at http://localhost:11434/api/generate or http://localhost:11434/api/chat.
  • LM Studio provides an OpenAI-compatible endpoint, usually running at http://localhost:1234/v1/chat/completions.

Because these local tools expose standard JSON-based REST APIs, any web client capable of making HTTP requests can send prompts and receive generated responses.

Overcoming Browser CORS Restrictions

When standard JavaScript executing inside a webpage attempts to call http://localhost, the browser blocks the request due to Cross-Origin Resource Sharing (CORS) security policies. Userscripts resolve this issue in two primary ways:

  1. Using GM_xmlhttpRequest: Userscript managers (like Tampermonkey, Violentmonkey, or Greasemonkey) provide special privilege APIs. By declaring @grant GM_xmlhttpRequest and @connect localhost (or @connect 127.0.0.1) in the script header, the request is executed outside the web page’s sandbox, bypassing CORS completely.
  2. Configuring Server Origins: You can configure the local server to accept cross-origin requests directly. For example, setting the environment variable OLLAMA_ORIGINS="*" allows standard web fetch() calls from any web page to reach the Ollama service.

Step-by-Step Integration Flow

  1. Extract DOM Data: The userscript reads selected text, input fields, or webpage content using standard JavaScript DOM methods.
  2. Construct Request Payload: The script formats the prompt and parameters into a JSON object matching the provider's API structure.
  3. Execute Network Call: The userscript sends a POST request to the local port hosting Ollama or LM Studio.
  4. Render AI Response: Once the local model returns the generated text, the userscript parses the JSON payload and dynamically updates the DOM to display the results to the user.

Primary Practical Applications

  • Contextual Web Summarization: Automatically summarizing lengthy documentation, news articles, or message boards with a single keyboard shortcut.
  • Privacy-First Data Processing: Translating or editing sensitive web forms offline without sending personal data to external cloud providers.
  • Automated Content Generation: Injecting intelligent drafting buttons next to text inputs on platforms like email clients or social media networks.
