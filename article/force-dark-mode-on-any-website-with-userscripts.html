Force Dark Mode on Any Website with Userscripts

Userscripts can easily force almost any website into dark mode, even if the site has no native dark theme support. By utilizing user script managers like Tampermonkey or Violentmonkey, browser scripts inject custom CSS styles or JavaScript code directly into web pages to invert colors, alter background elements, and adjust text contrast. This article breaks down how userscripts achieve forced dark mode, how you can set them up, and the potential limitations of using them.

How Userscripts Force Dark Mode

Userscripts manipulate a web page's structure and styling after the page loads in your browser. They force dark mode primarily through two main techniques:

1. Custom CSS Injection

The script injects custom Cascading Style Sheets (CSS) into the document head. This CSS explicitly overrides the site's default light backgrounds and dark text:

  • Backgrounds: Changes main containers, body tags, and sections to dark shades (such as #121212 or #181818).
  • Text: Changes paragraphs, headings, and links to high-contrast light colors (such as #E0E0E0).
  • Interactive Elements: Adjusts input fields, buttons, and borders so they remain visible against dark backgrounds.

2. CSS Filter Inversion

For a quick, automatic fix across complex elements, a userscript can apply a global CSS filter to the root HTML element:

  • filter: invert(100%) hue-rotate(180deg);

This flips light colors to dark while attempting to preserve original color hues. To prevent images, videos, and media from looking like photo negatives, the script applies a second inversion filter (invert(100%)) specifically to <img>, <video>, and <svg> elements.

How to Set Up a Dark Mode Userscript

To force dark mode on unsupported websites, follow these steps:

  1. Install a Script Manager: Add a browser extension such as Tampermonkey or Violentmonkey to your web browser.
  2. Find or Create a Script:
    • Pre-made scripts: Search repositories like Greasy Fork or OpenUserJS for site-specific dark themes or universal dark mode scripts.
    • Custom scripts: Write a basic script targeting a specific domain that applies custom styles on load.
  3. Enable and Run: Save the script and refresh the target website. The manager will execute the script automatically whenever you visit that site.

Advantages of Using Userscripts

  • Granular Control: You can edit the CSS directly to fix broken layout elements, change specific accent colors, or adjust contrast levels.
  • Low Resource Usage: Lightweight userscripts generally consume less memory than full-featured browser extensions.
  • Per-Site Customization: You can apply custom rules to single websites without affecting your entire browsing experience.

Limitations to Keep in Mind

  • Visual Artifacts: Automatic color inversion can sometimes result in low-contrast text, invisible icons, or weirdly shaded buttons.
  • Flash of Light Content: On slower connections or heavy sites, you may briefly see the original white background before the script executes.
  • Site Updates: If a website changes its internal HTML class names or structural CSS, a targeted userscript may stop working until it is manually updated.
