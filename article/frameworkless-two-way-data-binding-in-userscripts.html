Frameworkless Two-Way Data Binding in Userscripts

Userscripts often inject custom user interface elements into third-party web pages to extend functionality. Managing the state of these injected components efficiently without relying on heavy frameworks like React or Vue requires native JavaScript techniques. This article explains how userscripts achieve lightweight, frameworkless two-way data binding by combining native DOM event listeners with JavaScript Proxy objects or accessor descriptors.

Understanding Two-Way Data Binding

Two-way data binding maintains synchronization between a JavaScript data model (state) and a user interface element (DOM) in two directions:

  1. UI-to-State: User input on an HTML element automatically updates the JavaScript state.
  2. State-to-UI: Programmatic changes to the JavaScript state automatically update the HTML element's appearance or value.

Achieving this without external libraries requires leveraging native Web APIs that handle both event listening and property mutation tracking.

1. UI-to-State: Capturing User Input

To send updates from the DOM to the underlying state, userscripts attach standard DOM event listeners to injected elements.

When an injected input field, checkbox, or select menu changes, events such as input or change fire. The user script catches these events and assigns the new DOM value to the state variable.

const inputElement = document.querySelector('#injected-input');

inputElement.addEventListener('input', (event) => {
  // Update state when the user types
  state.username = event.target.value;
});

2. State-to-UI: Reacting to Data Changes

Updating the UI when JavaScript state changes programmatically requires detecting when a variable's value changes. Native JavaScript provides two main mechanisms for this: ES6 Proxy objects and Object.defineProperty().

Using the ES6 Proxy API

The Proxy object is the modern standard for reactive state management in vanilla JavaScript. A Proxy wraps a plain JavaScript object and intercepts operations such as property reads and writes.

When a property is modified on the proxied state, the set trap executes code to update the DOM automatically:

const initialState = { username: "" };

const state = new Proxy(initialState, {
  set(target, property, value) {
    // Prevent unnecessary DOM updates if value hasn't changed
    if (target[property] === value) return true;

    target[property] = value;

    // Update bound DOM elements
    if (property === 'username') {
      const input = document.querySelector('#injected-input');
      if (input && input.value !== value) {
        input.value = value;
      }
    }
    return true;
  }
});

Using Object.defineProperty()

For environments where Proxy objects are not preferred, explicit getters and setters define reactivity on specific object properties:

const state = {};
let usernameValue = "";

Object.defineProperty(state, 'username', {
  get() {
    return usernameValue;
  },
  set(newValue) {
    if (usernameValue === newValue) return;
    usernameValue = newValue;
    
    const input = document.querySelector('#injected-input');
    if (input) input.value = newValue;
  }
});

3. Combining Both Directions safely

A complete two-way data binding system links the DOM event listeners directly to the reactive state wrapper.

To prevent infinite loops—where updating the DOM triggers an event that updates the state, which in turn updates the DOM again—equality checks must be enforced in both the state setter and the DOM event listener before applying updates.

Complete Lightweight Implementation

function bindInput(inputSelector, stateProxy, key) {
  const element = document.querySelector(inputSelector);
  if (!element) return;

  // Set initial UI value from state
  element.value = stateProxy[key] || "";

  // UI -> State
  element.addEventListener('input', (e) => {
    if (stateProxy[key] !== e.target.value) {
      stateProxy[key] = e.target.value;
    }
  });
}

// State declaration with reactive UI update (State -> UI)
const state = new Proxy({}, {
  set(target, key, value) {
    if (target[key] === value) return true;
    target[key] = value;

    // Direct UI mutation based on property key
    const boundElement = document.querySelector(`[data-bind="${key}"]`);
    if (boundElement && boundElement.value !== value) {
      boundElement.value = value;
    }
    return true;
  }
});

// Usage after injecting HTML elements into the host page
bindInput('[data-bind="username"]', state, 'username');

Benefits for Userscript Development

  1. Zero External Dependencies: Keeps the script bundle size minimal and reduces execution overhead on host pages.
  2. Fast Execution: Direct DOM updates execute faster than virtual DOM diffing engines.
  3. Sandbox Compatibility: Native state traps work predictably inside userscript sandbox environments like Tampermonkey or Violentmonkey without requiring special build tools or bundlers.
